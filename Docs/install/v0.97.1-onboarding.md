# v0.97.1 reconciler-as-cadence — onboarding

After `sauce update --bump-pins` lands v0.97.1 in your consumer vault:

## Single step: Sync scheduled tasks

From **claude.ai's Cowork UI** chat (NOT Claude Code CLI):

```
/cowork sync-scheduled-jobs
```

Rail A:
- Composes new wrapper bodies for the existing 5 cadences
- DETECTS the new `reconcile-cowork` cadence in contract v0.35.1
- Creates `cowork-reconcile-cowork-<engagement_id>` tasks per enabled engagement
- Pushes via `update_scheduled_task` / `create_scheduled_task`

Your tuned cron schedules on existing tasks are NEVER touched. New reconcile-cowork tasks default to `0 3 * * *` (nightly 03:00 local).

## Uninstall the local launchd reconciler (if you ran --install-launchd previously)

The launchd path is deprecated as of v0.97.1. To remove:

```bash
launchctl unload -w ~/Library/LaunchAgents/com.<user>.cowork-reconciler.plist
rm ~/Library/LaunchAgents/com.<user>.cowork-reconciler.plist
```

(You already uninstalled both machines per the 2026-06-09 conversation.)

## What's still available

`sauce reconcile-cowork` (without `--install-launchd`) keeps working — useful for `--dry-run` previews and one-off manual reconciliation.

`sauce reconcile-cowork --install-launchd` keeps working for one cycle (v0.97.x) with a deprecation notice. Removed in v0.98.0+.
