# v0.97.0 cowork-rethought-2 — onboarding (one-time setup)

After `sauce update --bump-pins` lands v0.97.0 in your consumer vault:

## Step 1: Install the local reconciler (one-time, per machine)

```bash
sauce reconcile-cowork --install-launchd
```

This writes `~/Library/LaunchAgents/com.<user>.cowork-reconciler.plist` and loads it with `launchctl`. Schedule: nightly 03:00 local. Logs: `~/Library/Logs/cowork-reconciler.log` + `.err`.

You can verify with:

```bash
launchctl list | grep cowork-reconciler
sauce reconcile-cowork --dry-run --all-vaults
```

To uninstall: `launchctl unload -w ~/Library/LaunchAgents/com.<user>.cowork-reconciler.plist && rm ~/Library/LaunchAgents/com.<user>.cowork-reconciler.plist`

## Step 2: Sync scheduled tasks (one-time, after each cycle)

From claude.ai's Cowork UI chat:

```
/cowork sync-scheduled-jobs
```

This composes the new wrapper bodies for every (cadence × engagement) pair and pushes them via `update_scheduled_task` (claude.ai scheduled-task MCP). **Your tuned cron schedules are NEVER touched** — only the prompt bodies update.

Report shows: N updated / N created / N warned (orphan) / N no-op.

Optional flags:
- `--dry-run` to preview without pushing
- `--engagement <id>` to scope to one engagement

## Verification

Next morning briefing fires the new wrapper → atomic note + `.cowork.json` sidecar appear in `spice/cowork/daily/<today>/`. Rating callout `> [!todo]+ Was today useful?` at end of body — tick the kinds that mattered.

That night at 03:00 MT, reconciler fires → updates `learned_weights:` frontmatter in `user-preferences.md` (`.bak` written first). Check `spice/cowork/context/reconciler-log.md` for the per-night summary.

## What changed under the hood

- **Orchestrator instructions** moved from SKILL.md bodies to canonical `data/orchestrator-instructions/<cadence>.md` files. SKILL.md is now a 5-line shim pointing at the canonical source.
- **Cron LLM** (in claude.ai's Cowork UI) reads the wrapper template prompt body directly — no more dead-code SKILL.md bodies that never loaded.
- **Sidecars** (.cowork.json) written by the cron LLM via Obsidian MCP. Reconciler backfills any missing sidecars overnight from .md prose.
- **learned_weights** updates moved out of synthesize-day post-step (which never fired in production) into the local reconciler launchd job.
- **check-heartbeat** likewise moved to reconciler.

## Multi-machine note

If you have a second dev machine, run `sauce reconcile-cowork --install-launchd` there too. Each machine's launchd processes its own configured vaults independently. If both machines see the same vault (e.g. via Obsidian Sync), expect rare race conditions on user-preferences.md rewrites — `.bak` files preserved before each rewrite for recovery.
