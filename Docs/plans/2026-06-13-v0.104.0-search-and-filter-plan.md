## Stage S2 — Wire DocSearch into existing helpers

### Task 2: Extend `ProjectDocsIndex`

**File:** `platform/blueprints/project/helpers/project-docs-index.js`.

The current helper renders sections + quick + New Doc + dashboard chips + + New Section. Add DocSearch invocation at the top, and pipe `filterContext` through section card rendering.

Pseudo-code:
```javascript
async render(dv) {
  // ... existing project resolution + sections array ...

  // NEW: DocSearch strip
  const projectSlug = ...;
  const scopePath = `spice/projects/${projectSlug}/docs`;
  const filterCtx = customJS.DocSearch.render(dv, {
    projectSlug,
    scopePath,
    recursive: true,
    onChange: (ctx) => {
      // Full re-render of the container
      dv.container.empty();
      this.render(dv);  // ⚠️ pass ctx somehow — see implementation note below
    }
  });

  // ... existing rendering ...
  // When rendering each section card's doc count meta, filter:
  //   const docs = dv.pages(`"${scopePath}/${slug}"`).where(p => p.type === "doc-note");
  //   const filteredCount = docs.filter(p => customJS.DocSearch.matches(p, filterCtx)).length;
}
```

**Implementation note:** the simplest re-render strategy is to stash `filterCtx` on `this` (instance state) and have the next render() read it. Re-renders empty the dv container and call render again. The user-facing experience is identical to a debounced live filter.

- PDI-EXT-3: full-re-render onChange pattern (`dv.container.empty()` or equivalent).

### Task 3: Extend `SectionHub`

**File:** `platform/blueprints/project/helpers/section-hub.js`.

Same pattern. `scopePath` = the section's folder (depth 1: `docs/<slug>`; depth 2: `docs/<parent_slug>/<slug>`). `recursive` = true for depth 1, false for depth 2.

Filter the docs query before BeaconCards renders:
```javascript
const docs = dv.pages(`"${docsPath}"`)
  .where(p => p.type === "doc-note" && p.file.folder === docsPath)
  .where(p => customJS.DocSearch.matches(p, filterCtx));
```

Sub-section card counts also use `DocSearch.matches` (only when depth 1).
