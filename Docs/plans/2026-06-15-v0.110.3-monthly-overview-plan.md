## S1. Implement `monthly-overview.js` helper

**Subagent:** implementer-1 (general-purpose). Inline if simpler.

**Deliverable:** `platform/blueprints/finance/helpers/monthly-overview.js`.

**Spec:**
- Class `MonthlyOverview` with single `async render(dv)` method.
- Embed-dedup early-return + previous-instance removal (`:scope > .mo-root`).
- CSS root `mo-root` with `data-month` attribute.
- Static `PALETTE` constant (green/amber/red hex + bg rgba) — mirror BudgetSummary palette exactly.
- Methods:
  - `_monthKeyFromPage(page)` — returns `YYYY-MM` or null.
  - `_readPaychecks(dv, monthKey)` — `dv.pages` query filtered by `pay_period_start.startsWith(monthKey)`.
  - `_readDebts(dv)` — `dv.pages('"spice/finance/debts"').where(p => p.type === "debt")`.
  - `_sumIncome(paychecks)` — Σ `paycheck_amount` (defensive).
  - `_sumActuals(page)` — Σ `categories[*].actual` (defensive).
  - `_sumDebtPaid(paychecks)` — flatten `expenses[]`, filter `paid: true && debt: <string>`, sum `amount`.
  - `_fmtMoney(n, {signed?})` — currency formatter with optional signed prefix.
  - `_toneForNetCash(net, income)` — green/amber/red based on §2.3 thresholds.
  - `_renderBand1(root, income, spending, debtPaid, net)` — four flex cells.
  - `_renderBand2(root, monthKey, debts)` — total debt + MoM delta pill.
  - `_renderBand3(root, paychecks, debts)` — tiny sources footer.

**Conventions:**
- Pure read-only. NEVER writes; NEVER mutates frontmatter.
- All inline styles via `element.style.cssText` (matches BudgetSummary pattern).
- `font-variant-numeric: tabular-nums` on all numeric cells.
- No external dependencies (no `customJS.X` call from inside).

**Acceptance:**
- File present at `platform/blueprints/finance/helpers/monthly-overview.js`.
- `node -e "require('./platform/blueprints/finance/helpers/monthly-overview.js')"` doesn't crash on load (validates JS syntax).
- Class signature matches design §2.1.

**Commit:** `feat(finance): v0.110.3 S1 — MonthlyOverview helper`

## S2. Implement `applyFinanceBudgetMonthlyBandInjection` migration

**Deliverable:** edits to `platform/install.js`:
1. New `async function applyFinanceBudgetMonthlyBandInjection(tp, manifest, variables, history, git)` — list+walk Budget-YYYY-MM.md files in `spice/finance/budgets/<month>/` subfolders.
2. New `function _injectMonthlyBand(body)` — pure body transform; marker-guarded; idempotent.
3. Wire into `applyFinanceMigrations` orchestrator AFTER `applyFinanceBudgetBodyMigration` and BEFORE `applyFinancePaycheckBodyMigration`.
4. Add `module.exports.applyFinanceBudgetMonthlyBandInjection = applyFinanceBudgetMonthlyBandInjection;` at the bottom export block.
5. Update the orchestrator's docblock comment list to include the new step.

**Anchor regex priority:**
1. `<!-- budget-summary-v0.5.2 -->` marker comment present → inject BEFORE that line.
2. Else `BudgetSummary` dataviewjs block exists → inject BEFORE that block.
3. Else `FinanceStatus.renderBadge` block exists → inject AFTER that block.
4. Else frontmatter close → inject AFTER the closing `---\n`.

**Idempotency:** marker `<!-- monthly-overview-v0.6.3 -->` presence short-circuits at the top of `_injectMonthlyBand`.

**Acceptance:**
- `node -e "const m=require('./platform/install.js'); console.log(typeof m.applyFinanceBudgetMonthlyBandInjection);"` outputs `function`.
- Calling `_injectMonthlyBand(body)` twice on a sample body is byte-identical to one call.
