  - `class TaskInteractions { ... }` — single class.
  - All 8 methods exposed as BOTH static and instance (delegator pattern from `task-parser.js` L39): `parseTaskLine(line) { return TaskInteractions.parseTaskLine(line); }`.
  - `parseTaskLine`: regex extract on inline fields. Strip `[[wikilink]]` from the `project::` capture. Tolerate the `- [x]` completed form. Inline-field discovery: iterate over `/\[(\w+)::\s*([^\]]+)\]/g`; title = the prefix before the first match.
  - `serializeTaskLine`: delegate to `customJS.ToDoCreateTask.serializePayloadToLine` when available, else 8-line inline fallback. Must produce identical output to the existing serializer for the one-shot mode payloads.
  - `actionItemsAnchor`, `todayCaptureAnchor`: literal constants `"<!-- ACTION_ITEMS_MARKER -->"` / `"<!-- TODAY_CAPTURE_MARKER -->"`.
  - `injectActionItemsMarker(body)` / `injectTodayCaptureMarker(body)`: pure transforms. Idempotent guards via `body.includes(anchor)`. Insertion site: line immediately before the opening ``` fence of the corresponding SectionLabel block. Find by string search for the exact SectionLabel args text: `class: "SectionLabel", args: [{ text: "Action Items" }]` / `text: "Today"`.
  - `findTaskLines(content, anchor)`: walks the body line-by-line tracking fence depth; returns array of `{ idx, line, parsed }`. Respect optional `anchor` scope (start at the marker line; stop at the next SectionLabel block or EOF).
  - `appendTask(filePath, payload, opts)`: reads file via `app.vault.adapter.read` (CLI parity) or `app.vault.getAbstractFileByPath` + `app.vault.read` (live Obsidian); dispatches on the file's frontmatter `type:`; writes back via `app.vault.process(file, content => ...)`. Returns `{ ok: boolean, reason? }` — NEVER throws.
  - `replaceTaskAt(filePath, lineIdx, newLine)`: same atomic pattern; guard `^- \[[ x]\] ` on the existing line.
  - Cold-load safety: every `customJS.X` access uses `window.customJS?.X?.method` (per landmine #2).
