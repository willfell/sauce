### Helpers changed (project blueprint only)

**`project-docs-cards.js`** — Docs hub converted from a BeaconCards stacked auto-fit grid to `layout: "row"` single-column list rows (mtime-desc ordering — BeaconCards default). Right-side meta shows `created <MMM D> · edited <relative>` via new `_formatCreated`, which reads the canonical `created_at` property, handles both Luxon DateTime and string shapes, and falls back to `file.ctime`. Each row carries an accent file glyph. Fixed latent bug: the old code sorted and subtitled on the dead key `p.created` (doc-notes carry `created_at`), so the subtitle rendered empty and the sort silently fell through to BeaconCards default.

**`project-nav-buttons.js`** — Main project nav row now delegates to `customJS.AccentButton.render(container, {label, icon, onClick, flex: true})`, giving it identical styling to the New Doc / New Note buttons by construction and stretching the row full-width. The hand-rolled `btnStyle` + hover handlers are gone. Top divider margin raised 6px → 14px for breathing room below the "PROJECT" label. Workstream widget, action row, and task tiles are UNTOUCHED. Restyle scope was intentionally limited to the project nav row only — SpaceNavButtons, finance, and trips remain muted (nav-vs-action color distinction intentionally broken only where asked).

## Discoveries

1. **Stale guide command (FIXED this cycle).** Both the plan and `Docs/agent-guides/build-test-verify.md` § Self-install used `node platform/install.js .` — the installer actually requires `--vault <path>` (`node platform/install.js --vault . --auto-approve`). Fixed in build-test-verify.md as part of S5 cycle-close. Reinforces the "verify invocations before authoring plan steps" lesson.

2. **Rules-regen cadence is blueprint-version-gated.** `ranch/rules/*.json` only rewrites when the owning blueprint version bumps. First project-blueprint regen since v0.61.0 (2026-05-18) dropped accumulated duplicate contributions (doc-note.json 7 entries → 1; project.json 19 scopes → 1) — benign dedup by the current installer, but the diff looks like mass deletion. Future cycles should not panic at a rules diff after a blueprint bump.

3. **FA3-PROJ-1 version-floor is an enumerated alternation.** The assert currently uses `^1\.(13|14|15)\.\d+$` extended by hand this cycle. Carry-forward: convert to numeric minor-compare before the list grows unwieldy.
