## Lessons

1. **Verify the source-of-truth rule body before promoting.** The v0.89.0 canonical wikilink rule was already injected into `effective_hard_rules[]`; the bug was rule-ordering (last vs first) + rule-body language (no explicit precedence assertion vs microscope). Spec-time code review caught this; the original design assumed the rule was missing entirely and would need adding.

2. **Live verification matters even for "deterministic" deploys.** v0.89.1's HC test suite was 100% green and all 1482 sub-asserts passed; the wiring was structurally correct on disk. But the LLM didn't actually emit wikilinks — the soft prompt didn't take. Only running the morning briefing + EOD on a real M365 connector revealed the gap. Future cycles touching LLM behavior should keep a live-verification expectation as cycle-close gate.

3. **EOD-mode vs prefs-mode is a hidden axis.** Today's EOD ran in legacy mode (per evidence: "Late emails" warning callout language is legacy-side, no chat section emitted). Legacy mode bypasses the entire envelope wiring. WS-B's prose imperative is one mitigation; making the legacy fallback Notice LOUDER (PREFS UNAVAILABLE prefix) is another. If verification tomorrow shows EOD still legacy-mode, the next step is to investigate why `read-user-preferences` returned non-ok on EOD but ok on morning (different sessions? prefs file edit timing? a different bug).

4. **Test path constants matter.** My initial HC-V0900-VERSION-A..D tests used `path.resolve(WORKSHOP, "..", "package.json")` which was wrong because the top-level WORKSHOP constant is already the workshop root (not `platform/`). Spec-time helper-loading caught this within one test run. The existing HC-V0891-VERSION-A..C uses a LOCAL `WORKSHOP = path.resolve(__dirname, "..")` inside the function scope = `platform/` dir, distinct from the global. Two definitions for the same name = subtle bug.

5. **Workshop convention assumes dogfood drift is OK for cowork SKILL.md.** HC-V0842-A1 byte-equality check is only for `space-daily-dashboard.js`; other dogfood mirrors (.claude/skills/cowork/*/SKILL.md) drift freely between cycles and CI tolerates it. Not all dogfood mirrors are byte-equal-checked.
