## Key implementation decisions

1. **lens_shift handled as morning-briefing.md conditional branch.** No separate lens_shift SKILL.md. `{{#if cadence_mode == "lens_shift"}}...{{else}}...{{/if}}` syntax in orchestrator-instructions.
2. **Static + fire-time + computed-at-emit token split.** `{{$today_*}}` tokens stay literal — LLM resolves at fire time. Eliminates timestamp-drift class.
3. **`reconcileVault` is synchronous, not async.** All sub-mechanisms (sidecar-backfill, learned-weights-update, heartbeat-check, reconciler-log) are sync.
4. **Legacy validator shape-tolerance.** `validateContract` accepts EITHER `wrapper_template` (legacy) OR `wrapper_template_source` (v0.97.0+) per cadence.
5. **Frozen legacy contract fixture** at `platform/test/fixtures/cowork/legacy-contracts/v0.34.1-scheduled-job-contract.json` — preserves byte-identical pre-v0.97 contract for HC-V0930-COMPOSE-SHAPE legacy asserts.
6. **CLI verb naming convention.** `cmd-reconcile-cowork.js` per sauce-cli.js VERBS table pattern (NOT `commands/reconcile-cowork.js` from the spec).
7. **Backwards-compat path resolution.** vault-config.md + user-preferences.md path resolution tries canonical first + legacy fallbacks.
