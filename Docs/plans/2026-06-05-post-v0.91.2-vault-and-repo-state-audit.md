## 5. Future-mechanism wants surfacing from this audit

These bubble up from the vault state + the trajectory of the v0.91.x layer-cake work:

### High-value, well-scoped

1. **Layer 6 — body-composition deterministic backstop.** The natural next layer in the v0.91.x defense stack. Mechanism shape: orchestrator's body-composition step (Step 14 in MB) invokes the compose-helper via a Bash `node -e` block, captures stdout, writes it verbatim. No LLM judgment between the helper output and the write. Precedent: gather-finance-cc-today + other gather sub-skills already invoke node helpers via Bash. Scope: 6 invocation sites across 5 atomic-note orchestrators (composeMemoryCallouts, composeSemanticEchoesCallout, composeMidamMemoryCallout, composeEodMemoryCallout dual-output, composeWeeklyMemoryCallout, composeMonthlyMemoryCallout). **Closes FLN-v89-P0-1 deterministically.**

2. **v0.92.0 required-plugins (shelf design ready).** Adds `new-tab-default-page` to convenience@0.3.0 + `smart-connections` to smart-connections-bridge@0.2.0 as external_plugins. Closes the headspace Echoes-missing problem at install time. ~3 stages MINOR. Shelf design is at `Docs/plans/2026-06-01-v0.92.0-required-plugins-design.md` (modified in working tree today).

3. **`sauce doctor` cross-vault drift detection (FLN-v89-P1-3).** D6..D8 checks reading `~/.sauce/vaults.json` registry + computing per-vault drift; `sauce status` gets a summary line. Both vaults happen to be aligned right now, but only because the user manually ran `sauce update --bump-pins`. Detection should be automatic.

4. **`gather_log: []` frontmatter observability (FLN-v89-P1-4).** MB frontmatter gets `gather_log: [{sub_skill, status, reason, ms}]` — every sub-skill invocation outcome surfaced. Solves the accuris Echoes-silent-failure forensic gap. Self-explanatory; ~1 stage.

5. **ADO warning demotion to Notice (FLN-v89-P1-5).** When a served-by gather fails with `interactive_auth_required` or `no_credentials_stored`, demote to frontmatter `warnings: [<reason>]` and skip the body callout. ~0.5 stage; clears daily noise from accuris MBs.

6. **Synthesize-week thin-corpus guard (FLN-v89-P0-2).** `days_covered >= 3` check at Gather step 2; below threshold, exit silently + Notice. Prevents the headspace `days_covered: 1` pollution + the accuris empty-prompt stub. ~0.5 stage.
