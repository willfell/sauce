## NEW lessons

1. **Structured-output sub-skill API decouples downstream consumers from raw-md parse logic.** v0.86+ wire-through to midday-tripwire / eod-review / weekly-review / monthly-review becomes mechanical because each orchestrator calls `cowork:read-memory` with the same input shape and gets the same structured output back — no per-orchestrator parse work, no duplicated file-read prose. The primitive that v0.85.0 ships is what makes v0.86.0's scope feasible in a single MINOR.
2. **Helper-extract + golden-fixture pattern is the canonical byte-identical guarantee for prose-refactors.** Precedent now spans three cycles: v0.79.0 `composeMicroscope`, v0.80.0 `composeSibling`, v0.85.0 `composeMemoryCallouts`. When a refactor's safety requirement is "output prose must remain byte-identical to the pre-refactor version," extract the prose composition into a pure helper + assert byte equality against a golden fixture captured BEFORE the refactor lands. The diff that landed in step 3a is then ~3 lines (two read-memory calls + one helper invocation), not a 60-line in-prose substitution.
3. **Polish-prelude fold works when each prelude item has its own tight HC sub-assert that lands in the same commit.** 4 prelude items + 8 core stages = 16 commits across 12 logical stages; each prelude commit was small + scoped + atomically verified. Avoid the temptation to defer prelude polish to a follow-on PATCH unless the polish surface is genuinely independent.
4. **Mid-cycle cross-chat cohabitation works when blueprint scopes are disjoint.** v0.84.2/3/4 daily-blueprint polish PATCHes landed cleanly alongside v0.85.0's cowork-blueprint work. The workshop_version drift (0.84.1 → 0.84.4) was a single line absorbed at S11. Future cycles where ANOTHER blueprint might run concurrently can plan for the absorption at the version-bump stage.
5. **Parser correctness: 5 defects surfaced in code review against real-world fixtures.** The S6 polish commit `c2ac5c2` fixed (a) CRLF line-ending tolerance; (b) bare frontmatter values (no quotes); (c) back-to-back tick stanzas without separator; (d) paragraph collapse on whitespace-only lines; (e) non-bullet bleeding into carry-forward bullets. All caught BEFORE the byte-identical contract on `composeMemoryCallouts` was load-bearing — i.e., the parser was hardened against real-world synthesize-day + capture-tick output shapes before downstream call-sites depended on it.
6. **HC-V0840-C* supersedure pattern.** When a refactor obsoletes prior-cycle prose assertions, remove them in the same commit as the surface refactor — not in a follow-on cycle. Leaving them RED across cycle boundaries muddies the smoke output. Leave a comment-stub at the original site documenting the rationale (FLN-v85-2).
7. **Test-pin escape hygiene.** Smoke regex `/synthesis\.md/` was authored at S5 assuming unescaped naming_pattern, then S10's rule-engine canonical type required `^synthesis\\.md$` (escaped) JSON form to round-trip correctly. The S10 polish commit `bd10160` hardened the assertion to accept BOTH escaped + unescaped JSON forms (rule-engine wants escaped; pragmatic readers may use either). Future rule_fragment cycles should pre-flight assertion regexes against both forms at S0 (FLN-v85-3).
