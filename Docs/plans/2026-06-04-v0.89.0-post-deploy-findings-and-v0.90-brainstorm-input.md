## 3. What's working well (production positives)

1. **Reliability is impressive.** 3 days of fully unattended runs across 2 vaults. Capture-tick firing hourly (~13 ticks/day on headspace, ~11 on accuris). Synthesize-day producing voice-applied syntheses every EOD. Morning-briefing fires at the engagement's scheduled time. No silent failures observed.

2. **Voice contract holds across all output.** Casual + tough-love on debt + no emojis + no "leverage". Stylistic consistency across both vaults' synthesis paragraphs. v0.79.0 microscope/preferences foundation delivers as designed.

3. **Carry-forward propagation works end-to-end.** Yesterday's synthesis bullets → today's MB synopsis + Yesterday callout. Headspace's week-23 weekly synthesis pulled correctly from June 2's daily synthesis. Memory layer is feeding forward.

4. **Synthesis quality is high.** Both vaults producing chief-of-staff-grade briefings. Real signal, prioritized, accurate. Examples:
   - Headspace 06-04 MB opening: "You closed a 4-week migration last night — take the win, then go make the Cap1 Platinum payment..."
   - Accuris 06-04 MB opening: "Quiet overnight. Two direct Teams replies are waiting (EMS Linkerd downtime, Stefan's plugin DM)..."

5. **Synthesize-day's byte-identical tick preservation works.** Both vaults' synthesize-day logs explicitly verified `tick_count = [!example]- count` after the synthesis section replace. Tick data unchanged across day-synthesis fires.

6. **Memory log backlinks (v0.85.0 S3) work consistently.** Present + functional on every atomic note across both vaults.

7. **Self-correcting cross-day pattern emerged.** DMV appointment date was wrong in Wednesday's MB (carried from stale calendar entry). Wednesday's EOD synthesis corrected it to June 11. Thursday's MB synopsis reflects the correction. Memory layer is acting as a self-correcting source-of-truth across day boundaries.

8. **Engagement-aware cadence.** Accuris's 17:20 synthesize-day + 17:30 synthesize-week vs headspace's 19:15 + 19:30. Both correct for their engagement profile. The v0.85.1 cron-fix worked as intended.

## 4. What's broken (P0 / P1 / P2)

### FLN-v89-P0-1: The v0.85.0 byte-identical contract is dead

**Observation:** Yesterday (2026-06-03), accuris's MB rendered `[!example]+ Yesterday at a glance` per the v0.85.0 spec; headspace diverged to `[!note]- Yesterday — Tuesday, June 2`. **Today (2026-06-04), BOTH vaults diverge.** Accuris: `[!note]- Yesterday's carry-forward (Wed, June 3)`. Headspace: `[!note]- Yesterday — Wednesday, June 3`.

**Root cause:** The MB orchestrator agent reads the SKILL.md prose "invoke composeMemoryCallouts helper" but doesn't literally invoke the JS function — it composes its own callout from the underlying memory data, applying voice judgment per engagement.

**Impact:** The v0.85.0 byte-identical contract that justified the golden-fixture HC sub-asserts (C3..C5) is not enforced in production. The compose helpers are unit-tested but never actually called.

**Worsening trend:** Yesterday 1-of-2 vaults compliant; today 0-of-2.

**Fix shape candidate:** rewrite MB SKILL.md body composition to LITERALLY require helper invocation + add a pre-write self-check that diffs the rendered callout against composeYesterdayCallout(output_yesterday) output. Fail closed.

### FLN-v89-P0-2: Synthesize-week with `days_covered: 1` produces meaningless Tier 2

**Observation:** Headspace's `2026-W23/synthesis.md` exists with `days_covered: 1` (only June 2). Friday hasn't happened yet. The Tier 2 file represents 14% of a working week.

**Root cause:** Manual Run-now during permissions pre-approval fired synthesize-week on a Tuesday. The orchestrator's "no synthesized days → exit silently" guard at Gather step 2 didn't fire because there WAS 1 synthesized day. No upper-bound check.

**Impact:** Misleading Tier 2 record. Future read-memory queries against `tier: week, window: this-week` will return this thin synthesis as if it were a real weekly pattern. Pollutes the corpus.

**Fix shape candidate:** add `days_covered >= 3` guard in Gather step 2. Below 3, exit silently + Notice. Manual Run-now fires before Friday produce no file.

### FLN-v89-P1-3: Cross-vault version drift accumulates silently

**Observation:** Accuris on v0.88.2; headspace on v0.89.0. Visible drift via the `Tasks in motion` callout (headspace has it, accuris doesn't). No signal in `sauce status` showing drift.

**Root cause:** Per-vault bump-pins is a manual step. Cycles ship faster than user can update both vaults. Status command doesn't surface inter-vault drift.

**Impact:** Consumer vaults silently drift. Features land asymmetrically.

**Fix shape candidate:** `sauce doctor` command auditing blueprint version drift across known consumer vaults (configurable list). Per-vault drift status surfaced in `sauce status`.

### FLN-v89-P1-4: Echoes callout (v0.87.0) still hasn't surfaced

**Observation:** sc-bridge subscribed on accuris (verified 2026-06-03); SC reindex completed (verified); memory files in corpus index. But today's MB on accuris has no `[!quote]+ Echoes from your record` callout.

**Possible causes (unknown which):**
- gather-semantic-memory fired but min_similarity 0.45 filtered everything (corpus thin: 3 memory + ~6 daily atomic notes)
- gather-semantic-memory wasn't fired (MB orchestrator skipped step 3b)
- Sub-skill fired and threw but failed silently

**Impact:** Visibility gap. Can't determine whether v0.87.0 is working as designed (corpus dependent + min_similarity filtering) or broken (sub-skill not invoked).

**Fix shape candidate:** MB orchestrator logs every sub-skill invocation outcome to atomic note frontmatter under `gather_log: [{ sub_skill, status, reason }]`. Enables forensic diffing.

### FLN-v89-P1-5: ADO `served-by-unreachable` warning hits every accuris MB

**Observation:** Every accuris MB this week renders `> [!warning] Board status unavailable` because accuris-ado MCP requires interactive auth that scheduled fires can't complete.

**Impact:** Permanent noise callout on every accuris atomic note. Same callout every day. Reader habituates and stops reading warnings.

**Fix shape candidate:** When a served-by gather fails with a known-permanent reason (interactive-auth-required, no-credentials-stored), demote to Notice in frontmatter `warnings:` field. Don't render as callout in body.

### FLN-v89-P2-6: Compose helper proliferation has no consolidation path

**Observation:** Cowork helpers now include 7 compose-* functions (composeMemoryCallouts, composeMidamMemoryCallout, composeEodMemoryCallout dual-output, composeWeeklyMemoryCallout, composeMonthlyMemoryCallout, composeSemanticEchoesCallout, plus older composeMicroscope and composeSibling). All similar shape; slightly different inputs.

**Root cause:** v0.85.0/v0.86.0/v0.87.0 each shipped helpers per-orchestrator without consolidation. FLN-v86-1 candidate from the v0.86.0 result doc.

**Impact:** Each helper adds: source file + manifest files[] entry + dogfood materialization + golden fixture + HC sub-asserts. Drift accumulates per cycle.

**Fix shape candidate:** Defer until pattern stability obvious (v0.91+). Empirical observation says each compose helper's voice/shape diverges enough to justify separation today.

### FLN-v89-P2-7: Narrative docs are 5 cycles behind
