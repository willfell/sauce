## Lessons

1. **Closing-fence preservation is a class of bug.** Any helper that uses `body.match(/^(---\s*\n)([\s\S]*?)(\n---\s*\n?)/)` + `body.slice(fmMatch[0].length)` must explicitly preserve `fmMatch[3]` (the closing fence) in the reconstruction. The HC fixture pattern should always include body content AFTER frontmatter and assert `\n---\n` boundary preservation. Easy bug to ship; hard to catch without explicit assertion.

2. **Prose-narrative microscope formats are real.** v0.28.0's helper assumed structured patterns (`Inner circle (people): A, B, C` + bare bullets). Real-world microscopes vary — headspace's chat microscope uses bold-name patterns in prose paragraphs. Defensive widening + conservative false-positive filter + LLM-fallback prose extraction is the robust shape.

3. **Two-layer defense (deterministic + LLM-fallback) is the right pattern for parsers.** Pure deterministic regex over-extracts OR misses. Pure LLM-driven parsing is non-reproducible. Layering them — regex first for high-confidence structured patterns; LLM fallback for unstructured cases — gets reproducibility where possible and coverage where needed.
