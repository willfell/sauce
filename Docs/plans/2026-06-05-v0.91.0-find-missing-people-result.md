## Lessons

1. **Two complementary skills > one mega-skill.** discover-people (microscope-extraction) + find-missing-people (atomic-note-extraction) are easier to understand + test + iterate than a single mega-skill trying to do both. Each has narrow scope, well-defined inputs/outputs.

2. **Helper code reuse via exposed exports.** Exposing `_isLikelyPersonName` + `KNOWN_NON_PERSON_NAMES` from discover-people-helper (v0.91.0) for find-missing-people-helper to reuse keeps the false-positive filter list in one place. Underscore-prefix convention signals "internal but exposed for sibling skills" — acceptable hygiene compromise.

3. **The cowork.md slash body is becoming a drift risk.** Each new orchestrator requires a manual doc section in cowork.md. FLN-v91-1 captures this — auto-emit from `claude_surface[]` would prevent stale slash-body docs.
