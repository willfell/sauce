## Lateral context the next chat will want

- **The two-axis audit symmetry.** v0.80.0 wrote `## References`; v0.81.0 reads them. Writer-reader symmetry was the design lens. When adding new on-disk artifacts that get hand-edited by the user, anticipate the reader counterpart up front — silent-degradation is the dominant failure mode without it.

- **Pure-helper + I/O-orchestrator pattern.** v0.81.0 keeps the same split v0.79.0 + v0.80.0 established: deterministic logic in `helpers/*.js` (testable in isolation via HC cases); MCP/fs I/O in `skills/orchestrators/*/SKILL.md` (agent-driven). The audit-siblings orchestrator only does list-dir + read-file + render-callout work; all the audit logic lives in the helper. This is the pattern to keep applying.

- **Em-dash matters.** The audit helper's regex requires em-dash (`—`, U+2014) between `**<name>**` and the role description, matching what `composeMicroscope` writes. Hand-editing with a hyphen or en-dash silently flags the sibling as orphan. Documented in SKILL.md step 5. Future plan-template wisdom encoded in FLN-v81-2.

- **CS-MIG-1 lockstep dance is real and works.** v0.81.0 exercised the two-stage S5-fail / S6-fix sequence for the first time since FLN-v79-5 surfaced. The harness caught the count drift exactly as designed. Auto-derive is still the right long-term fix, but the manual dance is reliable when applied.
