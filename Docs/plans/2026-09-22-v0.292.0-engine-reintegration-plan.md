# Engine reintegration — plan (pointer)

**Cycle:** 2026-09-22 · **Version:** workshop 0.291.1 → 0.292.0 (predicted) · **Session:** `sauce-plugin-mktng-refactor`

The implementation plan for this cycle lives at [`Docs/superpowers/plans/2026-09-22-engine-reintegration.md`](../superpowers/plans/2026-09-22-engine-reintegration.md): sixteen TDD tasks from the deletions that need no replacement, through the engine's pure core (`yaml-lite`, graph, validator, ledger, reducer, vars, isolation, workers, nodes), the scheduler and `sauce run`, the note projection and human nodes, the launchd template, the always-on `engine` mechanism and installer heal, `sauce audit --engine`, the shipped `delivery-slice` graph with its stub-coordinator harness, the worktree sweep, docs and marketing, and cycle close.

Execution diverged from the plan in five recorded places, each surfaced by a harness rather than by review: the entry-node rule became "first declared node plus nodes nothing points at" (the original "no incoming unbounded edge" rule made repair steps reachable only through bounded edges into accidental entries); the YAML subset gained inline flow sequences; `${...}` substitution became bounded-recursive so a graph var can reference another; run ids gained a collision suffix when two runs mint in the same second; and `follow` stops at a human node by default (the harness hung polling a parked run). All five carry a test in `run-engine-graph.js`, `run-engine-smoke.js`, or `run-engine-delivery-graph.js`.
