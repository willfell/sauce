## 1. Scope

### 1.1 §1 NEW `cowork:gather-semantic-memory` sub-skill

**Location.** `platform/blueprints/cowork/skills/skills/gather-semantic-memory/SKILL.md` (FLN-v79-4 nested sub-skill dest).

**Inputs:**
```json
{
  "engagement_id": "<string, required>",
  "anchor_text": "<string, required — composed by caller from gather output>",
  "top_k": <number, optional, default 3>,
  "exclude_window": "last-30d | last-7d | { start: <ISO>, end: <ISO> } | none",
  "min_similarity": <number, optional, default 0.45>
}
```

**Output:**
```json
{
  "found": <boolean>,
  "matches": [
    {
      "path": "<vault-relative path to matched memory.md or synthesis.md>",
      "similarity_score": <float 0..1>,
      "day_or_week": "<YYYY-MM-DD or YYYY-Www>",
      "tier": "tick | day | week",
      "synthesis_excerpt": "<≤200 chars excerpt from matched file's synthesis paragraph>"
    },
    ...
  ],
  "anchor_text_used": "<echo>",
  "exclusion_count": <number — how many candidates were excluded by exclude_window>,
  "error": "<string or null — null on success>"
}
```

**Resolution / mechanic:**

1. Compose exclude globs from `exclude_window`:
   - `last-30d`: `spice/cowork/memory/<engagement>/<current YYYY>/<MM-Month for last 30d>/<YYYY-MM-DD for those days>/*.md`
   - `last-7d`: similar
   - `{start, end}`: walk days
   - `none`: empty
2. Invoke `sc-bridge semantic-search --vault <vault-root> --top-k <top_k> --min-similarity <min_similarity> --exclude-glob <glob>` for each exclude glob. Pass `anchor_text` as positional.
3. Parse JSON response. Filter results to `spice/cowork/memory/**` paths only (sub-skill is memory-scoped, not vault-wide).
4. Map each result to the output shape; extract `synthesis_excerpt` via the v0.85.0 `parseMemoryFile` / `parseSynthesisFile` helpers from `read-memory-helper.js`.
5. Prefer Tier 2 (synthesis.md) matches when present at min_similarity threshold; fall through to Tier 1 (memory.md) only when Tier 2 corpus is thin.

**Failure modes (graceful — never throws):**
- sc-bridge binary missing → return `{ found: false, matches: [], error: "sc_bridge_unavailable" }`.
- SC index missing/corrupt → return `{ found: false, matches: [], error: "index_unavailable" }`.
- Anchor text empty → return `{ found: false, matches: [], error: "empty_anchor" }`.
- Network/timeout (10s default per sc-bridge invocation) → return `{ found: false, matches: [], error: "timeout" }`.

### 1.2 §2 NEW `composeSemanticEchoesCallout` helper

**Location.** `platform/blueprints/cowork/helpers/compose-semantic-echoes-callout.js`.

**Signature.**
```javascript
composeSemanticEchoesCallout(gatherOutput) -> string
```

**Behavior:**

- Returns empty string when `gatherOutput` is null OR `found: false` OR `matches.length === 0`.
- Otherwise composes a `[!quote]+ Echoes from your record` callout listing up to `top_k` matches:

```markdown
> [!quote]+ Echoes from your record
> Patterns from your past that resemble today's signal:
> - **2026-04-15** (similarity 0.78) — _"That afternoon's CR review echoes Wed's deep-work block; same drag from email queue"_
> - **2026-W12** (similarity 0.71) — _"Week of focus blocks; finance receipts cleared on Thu"_
```

Per-match line: `> - **<day_or_week>** (similarity <score>) — _"<synthesis_excerpt>"_`. Italicized excerpt; 2-decimal similarity.

When all matches below min_similarity (`found: true` but filtered) → empty string.

## 6. Risks + mitigations

### 6.1 sc-bridge unavailable on consumer vault

User may not have sc-bridge installed (it's mechanism-subscribed; can be absent if subscription doesn't include it).

**Mitigation:** sub-skill returns `error: "sc_bridge_unavailable"` + empty matches. Helper returns empty string. MB body composition omits the callout. No throw; no user-visible regression.

### 6.2 SC plugin not installed in Obsidian

The `.smart-env/multi/*.ajson` corpus files require the Smart Connections plugin to be installed + indexed in the consumer vault.

**Mitigation:** sc-bridge returns `error: "index_unavailable"`. Same null-data clean-omit path as 6.1.

### 6.3 Corpus too thin for meaningful retrieval

At v0.87.0 close, accumulated memory ≈ 1-2 weeks × 2 vaults × ~16 ticks/day = ~200-400 memory.md files per engagement. Sequencing decision notes this is below the "200 ticks noisy" threshold for early-week deploys.

**Mitigation:** `min_similarity: 0.45` threshold filters out noise. Tier 2 prioritization (when synthesize-week has fired) surfaces higher-signal matches. As corpus accumulates over v0.87.0 → v0.88.0 interval (~2 weeks), signal density improves naturally.

### 6.4 Anchor text composition for MB step 3b

The sub-skill expects `anchor_text` ≤500 chars composed from dispatch_plan_summary + calendar + email. If those are empty (rare cold-fire), retrieval has no anchor.

**Mitigation:** MB step 3b's "skip if all three empty" short-circuit. composeSemanticEchoesCallout's empty-matches null-data return.

### 6.5 sc-bridge timeout blocking MB completion

sc-bridge is a Node spawn — if it hangs (e.g., during initial @xenova/transformers model load on first run), it could block MB.

**Mitigation:** 10s timeout per sc-bridge invocation (matches existing sc-bridge usage patterns). On timeout, return `error: "timeout"` + empty matches. MB continues without echoes callout.
