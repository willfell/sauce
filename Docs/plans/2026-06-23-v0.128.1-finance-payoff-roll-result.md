# v0.128.1 — finance payoff-roll fix + render harness (finance 0.10.1)

Post-ship hardening of the v0.10.0 planning layer so it's correct + crash-free for live testing.

## What shipped

1. **Payoff bug fix (`FinanceMath.simulateAvalanche`).** The simulation did not roll a paid-off
   card's freed **minimum** onto the next avalanche target — it let the minimum vanish, so the
   projection under-paid as cards died. On the headspace shape ($49,740 / $1,900-per-month) it
   computed a payoff of **2030-11 (53 months)** vs the hand-built Lever Protocol's ~mid-2029. Fixed
   to hold the **total monthly debt outlay constant** (`monthlyBudget = Σ active minimums + attack`;
   each month the target gets `monthlyBudget − minimums-paid`, so a freed minimum rolls forward) —
   the Lever Protocol "roll the whole payment to the next card." Now **2029-09 (~39 months)**, and
   `whatIf.skipAttackThisMonth` shows a real ~4-week slip (was 0). Envelope / allocation / savings /
   glide were already correct — only the projection changed.

2. **Render harness `run-finance-plan-widgets.js` (27 asserts).** Loads, instantiates, and calls
   `render()` on every v0.10.0 widget (FinancePlanDashboard incl. the Apply confirm-modal + `_writeAll`,
   PlanBand, SavingsSummary, SavingsCards, SavingsConfigEditor) and exercises FinanceNav mode
   detection, all against minimal Obsidian DOM / Dataview / app / customJS stubs (pattern from
   `run-v0109-projects-overhaul.js`). Catches the runtime crashes a source-contract test can't.
   Found **0 widget bugs** — every widget renders cleanly and produces the expected DOM.

3. **Smoke checklist `Docs/agent-guides/smoke-checklists/finance.md`** — a concrete Cmd+R walk on a
   deployed consumer vault, with the expected headspace numbers, covering the dashboard, Apply
   round-trip, PlanBand, the Edit-balance snapshot, the savings hub + New Savings, nav modes, the
   Plan tile, and the degrade-gracefully states.

## Lessons

- **Verify the engine against REAL consumer data before declaring done.** 63 green fixture asserts
  did not surface the missing avalanche min-roll — a 14-month payoff error. A throwaway "parse the
  real vault → run the engine → eyeball the numbers" script caught it immediately. Add this step to
  any cycle that ships a projection/aggregation engine.

## Carry-forwards

- **Allocation cross-cycle min-roll.** The per-cycle allocation display gives the target `min + attack`;
  correct while all cards are alive, but after a card pays off the freed minimum doesn't auto-roll
  into the displayed attack across cycles (the user bumps `attack_above_minimums`, or a future
  `total_debt_outlay` plan field). The payoff simulation already rolls within its projection.
- **G7 Copilot sync skill** (unchanged from v0.10.0) — `gather-budget-actuals` + `gather-cc-debt-snapshot`.
