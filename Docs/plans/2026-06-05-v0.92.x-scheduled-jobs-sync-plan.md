> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `cowork:sync-scheduled-jobs` orchestrator + `compose-scheduled-job-wrappers-helper.js` + `scheduled-job-contract.json` — emits paste-ready Cowork wrapper bodies for an engagement, fully aligned with the current sauce + cowork versions + the engagement's `prefs.mcps` state. Closes wrapper drift surfaced after the v0.91.x contract evolution stack.

**Architecture:** User-invocable orchestrator at `/cowork sync-scheduled-jobs [<engagement_id>]`. Pure-helper pattern (matches v0.85.0/v0.87.0/v0.92.0). `scheduled-job-contract.json` is the canonical data file with 5 cadence wrapper templates + 13 substitution tokens. Helper substitutes per-engagement variables (engagement_id, dispatch lines from `prefs.mcps`, voice notes excerpt, etc.) and emits a single output file per engagement.

**Tech Stack:** Node.js (helper); SKILL.md prose (orchestrator); JSON contract; HC harness.

**Dynamic-design commitment (B4):** No MCP brand strings in contract.json. Dispatch lines computed kind-by-kind from `prefs.mcps` — new MCP shapes work without contract changes.

**Design reference:** `Docs/plans/2026-06-05-v0.92.x-scheduled-jobs-sync-design.md`. Cite sections by number (§4 = contract schema; §5 = helper API; §7 = orchestrator structure). Read each cited section before executing.

**Sequencing:** v0.93.0 ships AFTER v0.92.0 (independent; see design §3.4). If v0.92.0 surfaces a PATCH (v0.92.1), this plan still produces v0.93.0 — version-number unaffected.

function validateContract(contract) {
  if (!contract || typeof contract !== "object") return { status: "failed:contract:invalid-shape:not-object" };
  for (const k of ["contract_version", "cadence_order", "substitution_tokens", "shared_clauses", "cadences"]) {
    if (contract[k] === undefined) return { status: `failed:contract:invalid-shape:missing-${k}` };
  }
  if (!Array.isArray(contract.cadence_order)) return { status: "failed:contract:invalid-shape:cadence-order-not-array" };
  for (const cad of contract.cadence_order) {
    if (!contract.cadences[cad]) return { status: `failed:contract:cadence-order-mismatch` };
    for (const f of REQUIRED_CADENCE_FIELDS) {
      if (contract.cadences[cad][f] === undefined) return { status: `failed:contract:invalid-shape:cadence-${cad}-missing-${f}` };
    }
  }
  return { status: "ok" };
}

function _validateSubstitutionTokens(contract) {
  for (const cad of contract.cadence_order) {
    const tmpl = contract.cadences[cad].wrapper_template;
    const matches = tmpl.match(TOKEN_RE) || [];
    for (const tok of matches) {
      if (!VALID_TOKEN_RE.test(tok)) return { status: `failed:contract:invalid-substitution-format:${tok}:cadence-${cad}` };
      if (tok.startsWith("{{$")) {
        const name = tok.slice(3, -2); // "{{$name}}" → "name"
        const key = `$${name}`;
        if (!contract.substitution_tokens[key]) return { status: `failed:contract:substitution-token-undeclared:${key}:cadence-${cad}` };
      } else if (tok.startsWith("{{shared.")) {
        const key = tok.slice(9, -2); // "{{shared.key}}" → "key"
        if (!contract.shared_clauses[key]) return { status: `failed:contract:unknown-shared-key:${key}:cadence-${cad}` };
      }
    }
  }
  return { status: "ok" };
}

function substituteTemplate(template, subs) {
  // subs: { "$name": value, "shared.key": value, ... }
  let out = template;
  for (const [k, v] of Object.entries(subs)) {

    if (input[f] === undefined || input[f] === null) {
      return { file_md: "", warnings: [], status: `failed:input:${f}:missing` };
    }

  const cv = validateContract(input.contract);
  if (cv.status !== "ok") return { file_md: "", warnings: [], status: cv.status };
  const sv = _validateSubstitutionTokens(input.contract);
  if (sv.status !== "ok") return { file_md: "", warnings: [], status: sv.status };

  const warnings = new Set();

  // Engagement-level substitutions
  const engagement = input.engagement;
  let engagement_label = engagement.label;
  if (!engagement_label) {
    engagement_label = engagement.id;
    warnings.add("engagement_label_fallback_used");
  }
  const mcpDispatch = composeMcpDispatchLines(input.prefs.mcps);
  if (mcpDispatch.warning) warnings.add(mcpDispatch.warning);

  let voice_notes_excerpt = "";
  const rawNotes = input.prefs.personality && input.prefs.personality.notes;
  if (!rawNotes) {
    warnings.add("empty_voice_notes");
  } else {
    let trimmed = rawNotes.replace(/\n/g, " ").trim();
    if (trimmed.length > 200) trimmed = trimmed.slice(0, 200) + "…";
    voice_notes_excerpt = trimmed;
  }

  // Contract version mismatch check
  if (input.contract.contract_version !== input.cowork_version) {
    warnings.add(`contract_version_mismatch:${input.contract.contract_version}:${input.cowork_version}`);
  }

  // Resolve disabled cadences
  const disabledFromEngType = (input.engagement_type_data.scheduled_jobs && input.engagement_type_data.scheduled_jobs.disabled_cadences) || [];
  const disabledCadences = new Map();
  for (const cad of disabledFromEngType) {
    disabledCadences.set(cad, "engagement-type");
    warnings.add(`cadence_disabled:${cad}:engagement-type`);
  }
  for (const cad of input.contract.cadence_order) {
    if (input.contract.cadences[cad].disabled === true && !disabledCadences.has(cad)) {
      disabledCadences.set(cad, "contract");
      warnings.add(`cadence_disabled:${cad}:contract`);
    }
  }

  // Engagement-level substitution map (shared across cadences)
  const engSubs = {
    "$engagement_id": engagement.id,
    "$engagement_label": engagement_label,
    "$mcp_dispatch_lines": mcpDispatch.line,
    "$voice_notes_excerpt": voice_notes_excerpt,
    "$sauce_version": input.sauce_version,
    "$cowork_version": input.cowork_version,
    "$contract_version": input.contract.contract_version
  };
  // Shared-clause substitutions
  const sharedSubs = {};
  for (const [k, v] of Object.entries(input.contract.shared_clauses)) {
    sharedSubs[`shared.${k}`] = v;
  }

  // Compose frontmatter
  const warningsArr = [...warnings].sort();
  const fmLines = [
    "---",
    "type: cowork-scheduled-job-wrappers",
    `engagement_id: ${engagement.id}`,
    `sauce_version: ${input.sauce_version}`,
    `cowork_version: ${input.cowork_version}`,
    `contract_version: ${input.contract.contract_version}`,
    `generated_at: ${input.generated_at}`,
    `generated_by: ${input.generated_by}`,
    `warnings: [${warningsArr.join(", ")}]`,
    "---"
  ];

  // Compose preamble (engagement-level substitutions only)
  let preamble = substituteTemplate(input.contract.preamble_template, engSubs);

  // Compose H1
  const h1 = `# Cowork scheduled-job wrappers — ${engagement_label}`;

  // Compose conditional warnings callout
  let warningsCallout = "";
  if (warningsArr.length > 0) {
    warningsCallout = "> [!warning]+ Warnings from generation\n" + warningsArr.map(w => `> ${w}`).join("\n");
  }

  // Compose collapsed "How to use" callout — wrap preamble lines with > prefix
  const preambleLines = preamble.split("\n").map(l => l === "" ? ">" : `> ${l}`);
  const howToUseCallout = "> [!info]- How to use\n" + preambleLines.join("\n");

  // Compose per-cadence sections
  const sectionParts = [];
  let sectionIndex = 0;
  for (const cad of input.contract.cadence_order) {
    sectionIndex++;
    const cadDef = input.contract.cadences[cad];
    if (disabledCadences.has(cad)) {
      const reason = disabledCadences.get(cad);
      sectionParts.push(
        `## ${sectionIndex} — DISABLED — cowork-${cad}-${engagement.id}\n` +
        `<!-- section_contract_version: ${input.contract.contract_version} -->\n` +
        `<!-- disabled_by: ${reason} -->\n` +
        `\n` +
        `> [!example] This cadence is disabled for ${engagement_label}\n` +
        `> Reason: disabled via ${reason}. If this is wrong, edit \`spice/cowork/context/engagement-types/${engagement.type}.json\` and re-run sync.\n` +
        `\n` +
        `---`
      );
      continue;
    }
    // Cadence-level substitutions
    const cadSubs = Object.assign({}, engSubs, {
      "$schedule_hint": cadDef.schedule_hint,
      "$frontmatter_type": cadDef.frontmatter_type,
      "$output_path_template": cadDef.output_path_template,
      "$orchestrator_skill_name": cadDef.orchestrator_skill_name,
      "$sub_skill_name": cadDef.sub_skill_name,
      "$cadence_tone_hint": cadDef.cadence_tone_hint
    });
    const substituted = substituteTemplate(substituteTemplate(cadDef.wrapper_template, cadSubs), sharedSubs);
    // Mode 4 post-render leak check
    if (substituted.includes("{{")) {

      `\n` +
      "````\n" + substituted + "\n````\n" +
      `\n` +
      `---`
    );
  }

  // Stitch file together
  const topParts = [fmLines.join("\n"), h1];
  if (warningsCallout) topParts.push(warningsCallout);
  topParts.push(howToUseCallout);
  topParts.push("---");
  const file_md = topParts.join("\n\n") + "\n\n" + sectionParts.join("\n\n") + "\n";

  return { file_md, warnings: warningsArr, status: "ok" };
}

# cowork:sync-scheduled-jobs

User-invocable orchestrator that emits the canonical Cowork scheduled-job wrapper bodies for an engagement to a paste-ready file.

## What it does

Reads the engagement's current state (vault-config, user-preferences, engagement-types) + the canonical scheduled-job contract for this cowork version + emits a paste-ready file at `spice/cowork/scheduled-job-wrappers/<engagement_id>.md` containing 5 wrapper bodies (one per cowork cadence) the user copies into claude.ai's Cowork UI.

The wrapper contract evolves with each cowork v-bump that touches the cron runtime (v0.91.1 added path-guard prose; v0.91.3 added connectivity prose; v0.92.0 added body-shape write-guard mentions). After every sauce update, re-run this skill to get current wrapper text.

## When to invoke

- First-time engagement setup (after `sauce wizard`).
- After every cowork blueprint MINOR bump (cron contract may have changed).
- On user demand if claude.ai cron output starts misbehaving.

## Inputs

- `engagement_id` (string, OPTIONAL): the engagement to sync. When omitted: orchestrator auto-resolves via the v0.90.0 discover-people pattern — default-if-one auto-picks single engagement; ask-if-many prompts user to choose.
```
