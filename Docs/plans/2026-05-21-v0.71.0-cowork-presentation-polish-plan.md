# v0.71.0 — Cowork Presentation Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Polish the cowork presentation layer end-to-end — display-name map for the 6 atomic-note types, required `summary:` frontmatter, nav-button-at-top, scoped cowork-hub ActivityFeed panels, runtime MCP-availability detection in gather-* skills, and an Obsidian-native body-shape contract (admonitions + tables) in the 6 write-run-note sub-skills. Bundles two v0.70.0 carry-forwards: a `groupPreviewBuilder` opt on activity-feed and per-cadence pill colors in the daily dashboard.

**Architecture:** Extend `activity-feed` mechanism (0.4.0 → 0.5.0) with two additive opts — `groupLabels` and `groupPreviewBuilder` — that the v0.70.x framed renderer consumes. Extend `cowork` blueprint (0.11.0 → 0.12.0) with: (a) `summary: required` + `warnings: optional` on the 6 atomic-note rule_fragments; (b) body-shape contract in the 6 `write-run-note-*` sub-skills; (c) runtime MCP-detection pattern in the 3 `gather-*` skills; (d) updates to 15 per-engagement default prompts; (e) scoped+framed ActivityFeed in 3 cowork hub templates. Extend `daily` blueprint (0.10.1 → 0.11.0) with `SpaceDailyDashboard` consuming the new activity-feed opts plus 6 cowork-* entries in `_BLUEPRINT_PILL_COLORS`. Add `display_names` object to `platform/rules/_canonical-vocab.json` as the single source of truth. Workshop bumps to v0.71.0.

**Tech Stack:** Node.js zero-dep test harnesses (`run-activity-feed.js`, `run-helper-cases.js`), Dataview-style CustomJS class source, Obsidian Markdown (Admonitions + tables + dataviewjs), JSON manifest files.

**Spec:** `Docs/plans/2026-05-21-v0.71.0-cowork-presentation-polish-design.md` (commit `027bb12`).
