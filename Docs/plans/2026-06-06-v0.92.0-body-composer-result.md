## Lessons

1. **Pre-existing file collisions.** My v0.92.0 design assumed `compose-body-helper.js` was a NEW file, but a v0.78.0 stub already existed at the same path with a different contract. The subagent overwrote it, breaking HC-V0780-E1 (5 sub-asserts). Resolved by retiring HC-V0780-E1 (the v0.78.0 contract is superseded). **Discipline:** before writing-plans for a new file, `ls` the target path AND grep for the file's name in existing code (helpers + tests).

2. **Plan-internal path discrepancy.** The plans referenced `platform/blueprints/cowork/run-helper-cases.js` but the actual harness lives at `platform/test/run-helper-cases.js`. Caught at S1; fed corrected paths to subagents at dispatch time. **Discipline:** verify actual file paths during plan writing, not just at execution.

3. **Workshop self-subscription drift.** The workshop's own `ranch/platform-subscription.json` was missing `people` (required by cowork@0.27.0 in v0.89.0) + had 4 stale mechanism pins. Workshop dogfood install was silently skipping cowork the whole time, meaning the v0.91.x cycles never fully exercised cowork install path on workshop self. Caught at v0.92.0 S0 baseline. **FLN-v92-4 queued:** 7 workshop blueprints (boards/products/to-do/journal/trips/finance/teams) remain unsubscribed; separate hygiene cycle should address.

4. **Consumer install requires Homebrew release.** Consumer vaults cache `installed.workshop_path` pointing at the brew Cellar version. After `brew upgrade sauce` ships v0.92.0, consumers can `sauce update` to pick up cowork@0.30.0 + the new body-composer surface. Pre-release, the consumer's cached path resolves to v0.91.3 (the brew-installed version), so direct `node /Users/willfellhoelter/projects/repos/sauce/platform/install.js --vault <consumer>` doesn't bridge the dev workspace → consumer gap. **FLN-v92-5 queued:** workshop_path cache invalidation on workshop bump (same root cause as v0.75.1 _resolveWorkshopPath bug in auto-memory).

5. **Cross-cadence orchestrator drift.** Step 14 was numbered Step 10 in midday-tripwire, Step 11 in eod-review, Step 15 in weekly-review + monthly-review. The 14a-14g sub-step labels are UNIFORM (they signal "the body-composition step has these 7 sub-actions") but the OUTER step number was preserved per cadence. The subagent handled this cleanly. The plan should have called out this cross-cadence step-number drift explicitly.

6. **Smoke test redirects vs retirements.** When v0.92.0 architectural changes removed prose patterns that legacy smoke tests asserted on, the subagent redirected the assertions to track the new source-of-truth equivalents (e.g., HC-V0751-H1 now checks for `semantic_index_unavailable` flag + `semantic-unavailable` block name rather than the removed "ONLY IF step 12b ran" prose). This is the right pattern when the architectural intent persists in a new shape. Different from retiring HC-V0780-E1 (where the architectural intent was fully replaced).
