## Curly-apostrophe drift (S1.1)

The spec §1.1 step 2 specified the new `naming_pattern` as `^[A-ZÀ-Ý][A-Za-zÀ-ÿ'’\\.\\- ]*\\.md$` — including the curly apostrophe `’` (U+2019). Intentional post-edit during S1.1 normalized this to two straight apostrophes `''`, dropping curly support. The plan's HC-V0880-PEOPLE-B accept/reject matrix was updated in lockstep before S1.7 ran. Downstream effect: person notes pasted from sources that auto-curl apostrophes (Word, Pages) will now flag audit; user can either rename them or revisit the regex in a future patch.
