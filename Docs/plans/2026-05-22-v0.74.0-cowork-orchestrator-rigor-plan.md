# v0.74.0 — Cowork Orchestrator Rigor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden the cowork v0.71.0 presentation contract end-to-end. Three workstreams in one cycle: (A) enforce body-shape via Claude-side self-check + add `title:` required frontmatter; (B) broaden midday-tripwire from finance-only to a `tripwire_aspects[]` model so w2-fte + consulting can fire on calendar drift / queue growth; (C) migrate the cowork write path off the Obsidian REST API to filesystem-first I/O and make `cowork:onboard-scheduled-jobs` the single conversational entry-point post-`brew upgrade sauce`.

**Architecture:** Cowork blueprint bumps 0.12.0 → 0.13.0. Three engagement-type JSON files (personal/w2-fte/consulting) bump 0.1.0 → 0.2.0 (additive `tripwire_aspects[]`). 6 `write-run-note-<orch>` SKILL.md bodies grow 3 new sections (`## Title composition`, `## Adaptive body skeleton`, `## Pre-write self-check`) and migrate their write step from `mcp__obsidian__create_note` to Bash `mkdir -p` + native `Write` + `wc -c` verify. `cowork:check-vault-routing` grows a `{ required: ["filesystem"] }` mode. `cowork:onboard-scheduled-jobs` gets a full rewrite (Welcome step 0 → preflight auto-delegate to `bootstrap-vault` → bulk-defaults question → per-cadence preambles → filesystem Read+Write copy with byte-count assertion → re-runnable state detection). `cowork:midday-tripwire` orchestrator broadens its preflight gate and per-aspect gather/decide branches. `gather-calendar` adds a `drift-check` mode; `gather-projects` adds a `tripwire-delta` mode. **No mechanism bumps.** Workshop bumps 0.73.0 → 0.74.0.

**Tech Stack:** Node.js zero-dep test harnesses (`platform/test/run-*.js`), Obsidian Markdown (Admonitions + tables + dataviewjs), JSON manifest files, native Claude Code tools (`Bash`, `Read`, `Write`, `Edit`).

**Spec:** `Docs/plans/2026-05-22-v0.74.0-cowork-orchestrator-rigor-design.md` (commit `76e43f0`).
