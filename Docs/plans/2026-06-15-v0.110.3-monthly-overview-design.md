## 2. Widget — `monthly-overview.js`

Lives at `platform/blueprints/finance/helpers/monthly-overview.js`. Conventions cribbed verbatim from `BudgetSummary` (S0 verification confirmed):

- Single async `render(dv)` exported method on a `MonthlyOverview` class.
- Embed-dedup: `dv.container.closest(".markdown-embed")` early-return; previous-instance removal via `:scope > .mo-root`.
- Hardcoded color palette (matches BudgetSummary):
  - `#16a34a` (green) / `rgba(22, 163, 74, 0.10)` bg
  - `#b45309` (amber) / `rgba(180, 83, 9, 0.10)` bg
  - `#dc2626` (red) / `rgba(220, 38, 38, 0.10)` bg
- Pure read-only — never writes; never mutates frontmatter.
- CSS root: `mo-root` (data-month attribute for inspection).
- Header marker (for installer migration idempotency, written as HTML comment): `<!-- monthly-overview-v0.6.3 -->`.

### 2.1 Render flow

```javascript
async render(dv) {
  if (dv.container.closest?.(".markdown-embed")) return;
  const prev = dv.container.querySelector(":scope > .mo-root");
  if (prev) prev.remove();

  const page = dv.current();
  if (!page?.file) return;
  if (page.type !== "budget") return;          // band only renders on Budget entities

  const monthKey = this._monthKeyFromPage(page);   // "YYYY-MM" string or null
  if (!monthKey) return;

  const paychecks = this._readPaychecks(dv, monthKey);
  const debts = this._readDebts(dv);
  const spending = this._sumActuals(page);
  const income = this._sumIncome(paychecks);
  const debtPaid = this._sumDebtPaid(paychecks);
  const netCash = income - spending - debtPaid;

  const root = dv.container.createEl("div", { cls: "mo-root" });
  root.setAttribute("data-month", monthKey);
  root.style.cssText = "...";                         // mirror BudgetSummary container style

  this._renderBand1(root, income, spending, debtPaid, netCash);
  this._renderBand2(root, monthKey, debts);
  this._renderBand3(root, paychecks, debts);
}
```

### 2.2 Data reads

- **`_readPaychecks(dv, monthKey)`** — `dv.pages('"spice/finance/paychecks"').where(p => p.type === "paycheck" && typeof p.pay_period_start === "string" && p.pay_period_start.startsWith(monthKey))`. Returns array of paycheck pages. Empty array if the paychecks folder doesn't exist (`dv.pages` returns empty proxy).
- **`_readDebts(dv)`** — `dv.pages('"spice/finance/debts"').where(p => p.type === "debt")`. Returns array of debt pages. Empty when debts sub-area absent.
- **`_sumIncome(paychecks)`** — `Σ paycheck_amount` (defensive: `typeof p.paycheck_amount === "number"`).
- **`_sumActuals(page)`** — `Σ (typeof c.actual === "number" ? c.actual : 0)` over `page.categories || []`.
- **`_sumDebtPaid(paychecks)`** — flatten `p.expenses || []` across all paychecks, filter for `e?.paid === true && typeof e.debt === "string" && e.debt.length > 0`, sum `e.amount` (defensive).
- **`_monthKeyFromPage(page)`** — prefer `page.month` if `/^\d{4}-\d{2}$/`; else parse from `page.file.name` (`/Budget-(\d{4}-\d{2})/`).

Defensive guarantees: every reducer tolerates `undefined`, non-arrays, and non-numbers. No `try/catch` — direct optional-chain + `typeof` guards.

### 2.3 Band 1 — headline

Four flex cells: Income · Spending · Debt paydown · **Net cashflow**.

- Cell label: 0.72em uppercase muted (mirror BudgetSummary `_renderBand1` label style).
- Cell value: 1.35em tabular-nums.
- **Net cashflow** value color:
  - `netCash >= 0` → green (`#16a34a`)
  - `netCash < 0 && |netCash| <= 0.10 * income` → amber (`#b45309`)
  - else → red (`#dc2626`)
- Sign-prefixed dollar value (`+$1,234.56` for positive; `-$1,234.56` for negative — keep the sign on positive so the affordance reads consistently).
- "Debt paydown" cell: if `debtPaid === 0 && debts.length === 0` (i.e. no debts tracked), render the cell with value "—" and muted color; do NOT subtract 0 from `netCash` math.

### 2.4 Band 2 — debt mini-row

Single row beneath Band 1 with thin top hairline (`1px solid var(--background-modifier-border)`).

- Left: "Total debt: $X" (Σ `current_balance`).
- Right: MoM delta pill:
  - For each debt, find `balance_history[]` entries within `[monthKey + "-01", monthKey + "-31"]` window (string-prefix match works because YYYY-MM-DD sorts lexicographically). If at least one debt has BOTH a first-of-month and last-of-month snapshot, compute aggregate delta = Σ `(last - first)` across those debts. Else: render "No MoM signal yet" muted pill.
  - Negative delta = debt went down = green; positive delta = debt went up = red; zero = muted.
- If `debts.length === 0`: render single-line "No debt tracked" muted text; skip the MoM pill.

### 2.5 Band 3 — sources strip

Tiny audit footer (0.72em muted):

- "From N paychecks (Σ paycheck_amount = $X), M debt entities surveyed."
- If `paychecks.length === 0`: "No paychecks dated this month — income shown as $0."

This band is intentionally tiny — the goal is "did the band see what I expected" not "browse my data."

### 2.6 Currency formatter

```javascript
_fmtMoney(n, opts = {}) {
  const abs = Math.abs(typeof n === "number" ? n : 0).toFixed(2);
  const parts = abs.split(".");
  const dollars = parts[0].replace(/\B(?=(\d{3})+(?!\d))/g, ",");
  const signed = opts.signed
    ? (n >= 0 ? "+" : "-")
    : (n < 0 ? "-" : "");
  return `${signed}$${dollars}.${parts[1]}`;
}
```

Tabular-nums on all numeric cells (`font-variant-numeric: tabular-nums`).

### 3.2 Migration body

```javascript
// applyFinanceBudgetMonthlyBandInjection — v0.110.3 (finance 0.6.3). Injects
// the MonthlyOverview dataviewjs block (marker-guarded by
// `<!-- monthly-overview-v0.6.3 -->`) immediately ABOVE the BudgetSummary block
// on every Budget-YYYY-MM.md. Body-text mutation only. Idempotent — marker
// presence short-circuits. Per-file failure-loud via history warning events.
async function applyFinanceBudgetMonthlyBandInjection(tp, manifest, variables, history, git) {
  if (!manifest || manifest.name !== "finance") return;
  if (!tp || !tp.app || !tp.app.vault || !tp.app.vault.adapter) return;
  const adapter = tp.app.vault.adapter;

  const budgetsRoot = "spice/finance/budgets";
  if (!(await adapter.exists(budgetsRoot))) return;

  const budgetFiles = [];
  try {
    const top = await adapter.list(budgetsRoot);
    for (const folder of (top.folders || [])) {
      try {
        const inner = await adapter.list(folder);
        for (const fp of (inner.files || [])) {
          if (/Budget-\d{4}-\d{2}\.md$/.test(fp)) budgetFiles.push(fp);
        }
      } catch (_e) { /* per-folder failure-loud */ }
    }
  } catch (e) {
    history?.push({ event: "warning", step: "finance_budget_monthly_band_injection", name: "finance",
      reason: `list failed for ${budgetsRoot}: ${e.message}`,
      git_commit: git.commit, git_tag: git.tag, git_dirty: git.dirty,
      attempted_at: new Date().toISOString() });
    return;
  }

  if (budgetFiles.length === 0) return;

  let touched = 0;
  for (const fp of budgetFiles) {
    try {
      const body = await adapter.read(fp);
      const result = _injectMonthlyBand(body);
      if (result.touched) {
        await adapter.write(fp, result.body);
        touched += 1;
      }
    } catch (e) {
      history?.push({ event: "warning", step: "finance_budget_monthly_band_injection", name: "finance",
        reason: `body migration failed for ${fp}: ${e.message}`,
        git_commit: git.commit, git_tag: git.tag, git_dirty: git.dirty,
        attempted_at: new Date().toISOString() });
    }
  }

  history?.push({ event: "info", step: "finance_budget_monthly_band_injection", name: "finance",
    reason: `${budgetFiles.length} budgets scanned, ${touched} bodies injected (MonthlyOverview block above BudgetSummary)`,
    git_commit: git.commit, git_tag: git.tag, git_dirty: git.dirty,
    attempted_at: new Date().toISOString() });
}

// _injectMonthlyBand — pure body transform. Idempotent.
function _injectMonthlyBand(body) {
  let out = body;
  let touched = false;

  const MARKER = "<!-- monthly-overview-v0.6.3 -->";
  if (out.includes(MARKER)) return { body: out, touched: false };
  if (/customJS\.MonthlyOverview|class:\s*["']MonthlyOverview["']/.test(out)) {
    // Already present without marker — inject marker only (no body change).
    return { body: out, touched: false };
  }

  const overviewBlock = `${MARKER}\n\`\`\`dataviewjs\nawait dv.view("ranch/views/customjs-guard", { class: "MonthlyOverview" });\n\`\`\`\n\n`;

  // Preferred anchor: inject BEFORE the BudgetSummary block.
  const summaryAnchorRe = /(<!--\s*budget-summary-v[\d.]+\s*-->\s*\n)|(```dataviewjs\s*\n[^`]*class:\s*["']BudgetSummary["'][^`]*```\s*\n)/;
  const m = out.match(summaryAnchorRe);
  if (m) {
    out = out.replace(summaryAnchorRe, `${overviewBlock}$&`);
    touched = true;
  } else {
    // Fallback: inject after the FinanceStatus.renderBadge block.
    const badgeBlockRe = /(```dataviewjs\s*\n[^`]*FinanceStatus\.renderBadge[^`]*```\s*\n)/;
    const m2 = out.match(badgeBlockRe);
    if (m2) {
      out = out.replace(badgeBlockRe, `$1\n${overviewBlock}`);
      touched = true;
    } else {
      // Last-resort fallback: inject after frontmatter close.
      const fmEnd = out.indexOf("---\n", 4);
      if (fmEnd !== -1) {
        const cutIdx = fmEnd + 4;
        out = out.slice(0, cutIdx) + `\n${overviewBlock}` + out.slice(cutIdx);
        touched = true;
      }
    }
  }

  return { body: out, touched };
}
```

### 3.3 `.sauce-backup` snapshot policy

Body-only mutation that's append-only is consistent with the v0.107.0 CF-2 posture (`applyFinanceBudgetBodyMigration` did NOT snapshot; the heal was deemed safe because it was provably append-only + marker-guarded). MonthlyOverview injection follows the same posture: **no per-file snapshot** before write. The migration only adds a marker + dataviewjs block; it never edits existing content. Idempotency check passes byte-equality on subsequent runs.

If a regression somehow strips content, the user has the standard recovery: brew downgrade + reinstall + `git checkout` against any local clone. Snapshotting on every Budget file across 12+ months × N years would be heavy for no documented value (no production fault has been observed in `applyFinanceBudgetBodyMigration` across the v0.107.0 / v0.108.0 / v0.110.0 install runs).

1. **Headline math sums `paid: true` debt-linked paycheck expenses, NOT `balance_history[]` deltas.** "What hit the books this month" semantics; balance_history is a Band 2 secondary signal.
2. **MoM debt delta is a Band 2 pill, not Band 1.** Band 1 stays clean four-cell income/spending/debt/net.
3. **Band placement: ABOVE BudgetSummary.** Cohesion view (this band) is the prominent layer; sliced view (BudgetSummary) is the supporting layer.
4. **PATCH bump, not MINOR.** Single helper + single migration + no schema change = additive PATCH.
5. **No `.sauce-backup` snapshot before the new migration.** Append-only marker-guarded body mutation matches v0.107.0 CF-2 posture which has been incident-free.
