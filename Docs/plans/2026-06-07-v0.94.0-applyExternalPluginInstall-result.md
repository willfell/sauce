## NEW lessons from v0.94.0 execution

1. **`installer.runInstall` is subprocess-spawning, not in-process.** S1.1 discovered that install.js's exported `runInstall` wraps `child_process.spawn(run-install.js)` — incompatible with in-process https mocking. Subagent added `runInstallInProcess()` shim in run-bootstrap.js as the correct seam. Future cycles that need install-pass tests should reuse this shim.

2. **bootstrap-lib resolution needs `workshopPath` fallback.** S1.2 discovered that `require("./bootstrap-lib/...")` fails when install.js is loaded from the workshop copy at `ranch/templater/platformInstall.js` (because __dirname becomes the ranch path, not platform/). Added a try-`__dirname`-then-fallback-to-`workshopPath/platform/bootstrap-lib` resolver with graceful skip if neither resolves. The signature changed: `applyExternalPluginInstall(tp, manifest, vaultPath, workshopPath, history, git)`.

3. **`vaultPath` derived from adapter, not target.path.** S1.2 discovered that `target.path` is the item-specific destination path, NOT the vault root. The new helper needs the vault root, so it uses `adapter.basePath || (typeof adapter.getBasePath === "function" ? adapter.getBasePath() : null)`. The design doc was wrong on this point.

4. **Test artifact leak.** S1.1 RED-state test runs created stale `mechanisms/test-epi*` directories at the workshop root (path leak before S1.2's bootstrap-lib fallback fixed the resolution). Cleaned up in S2 addendum. Future test code should be more defensive about path resolution OR explicit about cleanup.

5. **Silent scope-expansion temptation.** S1.4 subagent silently included ranch/platform-subscription.json lockstep (planned for S2) when version-sync caught it as "drift" during preflight verification. Lesson 5.6 (from v0.93.3) says surface scope adaptations explicitly, but the more subtle pattern is: subagents may quietly merge clearly-needed work that the plan attributes to a later stage. Plans should make these dependencies explicit (e.g., "S1.4 MUST also bump ranch lockstep or preflight fails").
