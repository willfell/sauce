## Lessons

- **`sauce update --bump-pins` already runs the installer.** The long-quoted `sauce update --bump-pins && sauce install` is wrong — `install` is not a CLI verb (valid: bootstrap/update/reinstall/...). `update --bump-pins` bumps the subscription pins AND runs a full install in one step. The `&& sauce install` tail has been silently erroring (harmlessly) in prior deploys. `build-test-verify.md` should be corrected.
- **Migration tests: prefer direct-invocation of the exported `apply*` over seed anchors when the blueprint version isn't bumping.** Seed anchors only get exercised when a per-item version delta defeats the install.js:384 short-circuit. Direct invocation against a tmp vault is version-independent and permanent.
- **A "no consumer behavior" PATCH still warrants the full regression+release rigor** when it's the foundation a feature cycle will build on.
