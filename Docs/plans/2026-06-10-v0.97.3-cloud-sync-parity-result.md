# v0.97.3 cloud-sync-parity — result

## TL;DR

Closes the cloud/local-sync divergence introduced by v0.97.2. The `ANTI-DELEGATION (NON-NEGOTIABLE)` directive, the fire-time `PRELUDE` block, and the trailing `DONE` block all moved OUT of `compose-scheduled-job-wrappers-helper.js` JS literals and INTO `_shared-clauses.md` as three new clause heading blocks. All six orchestrator-instructions cadence files now reference them via `{{shared.*}}` at top + bottom. The JS composer becomes a pure token substituter — no special-case prepending or appending.

The architectural significance: source of truth for ALL wrapper content now lives in vault markdown files. Cloud sync (claude.ai Cowork UI, no Node runtime) and local sync (sauce CLI, Node helper) produce byte-identical wrappers because both rails read the same files and substitute the same tokens.

## Updated user prompt for re-running cloud sync

Previously the cloud-sync orchestrator needed special-case logic to "prepend the ANTI-DELEGATION directive" because the directive lived only in the JS helper. With v0.97.3, the cloud-sync prompt is simpler:

> Read each `spice/cowork/data/orchestrator-instructions/<cadence>.md`. Read `_shared-clauses.md`. Substitute every `{{shared.<key>}}` from the shared-clauses parse. Substitute every `{{$<token>}}` from the engagement context + prefs + contract. Leave `{{$today_*}}` literal (resolved at fire time). Verify the resolved wrapper contains all three substrings: `ANTI-DELEGATION (NON-NEGOTIABLE)`, `PRELUDE — fire-time setup`, `cowork:<cadence> complete`. If all present, push the wrapper to the scheduled task. If any missing, abort and surface a warning.

That prompt — minus the directive verifications — mirrors what the local JS composer does. Both rails now converge.

## Lessons captured

- **Source of truth must be readable by every rail.** The v0.97.2 JS-only guardrail looked correct because it tested fine locally — but the cloud rail had no way to see it. Lesson: every load-bearing wrapper string must live in a vault file, not a JS literal.
- **Cloud sync's guardrail-verify is the right safety net.** It correctly aborted today rather than pushing a wrapper without the v0.97.2 directive. That's the behavior we want — fail loudly when source doesn't match expectations.
- **The cloud LLM is a perfectly capable token-substituter.** Once the text lives in markdown, the cloud LLM can substitute `{{shared.*}}` and `{{$<token>}}` reliably. No special handling needed.
