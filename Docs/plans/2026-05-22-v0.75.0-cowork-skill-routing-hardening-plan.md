# v0.75.0 — Cowork Skill-Routing Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the v0.74.0 body-shape-contract gap that opens when an agent runs in a multi-context Claude Code session (scheduled-tasks-MCP-driven cron fires, multi-machine remote control, IDE plugins with different skill-loading models). Bundle three additional workstreams in the same cycle: Smart Connections semantic retrieval (new mechanism + cowork sub-skill + 3 orchestrator integrations), the v0.74.0 S6 engagement-types path-resolution fix, and FLN-v67-7 `sauce update --bump-pins` consumer subscription auto-bump.

**Architecture:** Four workstreams.
- **A — Cowork skill-routing hardening.** Three layers + audit harness check. L1 rewrites ~69 `Use Skill cowork:<X>` references across 5 orchestrator SKILL.md + onboard-scheduled-jobs SKILL.md to a `READ .claude/skills/cowork/skills/<X>/SKILL.md in full ... then apply ...` form. L2 adds a post-write structural verification step (re-read + regex-scan markers + frontmatter + delete-on-miss + return `failed:contract-violation:<field>`) to all 5 atomic-note-writing orchestrators. L3 enriches the prompts that `onboard-scheduled-jobs` Step 6 registers (direct mode + paste mode). HC-V0750-A1 audit-grep harness fails-closed on any naked `Use Skill cowork:` reference. Appendix in design doc ships the 20-entry immediate-mitigation recipe (4 vaults × 5 cadences).
- **B — Smart Connections semantic retrieval.** New mechanism `smart-connections-bridge@0.1.0` (Node CLI `sc-bridge` reading `.smart-env/multi/*.ajson` directly with `{{module_directory}}` substitution; vendors `@xenova/transformers` + `TaylorAI/bge-micro-v2`). New cowork sub-skill `gather-semantic-related` renders a `> [!example]+ 🧩 Related context` callout with `Semantic index age:` lag-line in Synopsis. Integrates into morning-briefing (per-event semantic-search, capped at 5 events), eod-review (find-related on today's daily note), weekly-review (aggregated find-related across week's daily notes with dedupe + coverage ranking). Engagement-aware via new `render_aspects.semantic_related` field (additive bump engagement-types 0.2.0 → 0.3.0). Index-absent vaults degrade gracefully (one-line warning callout).
- **C — Engagement-types path-resolution fix.** `onboard-scheduled-jobs/SKILL.md` Step 2 rewritten to use `workshop_manifest_path` (mirroring bootstrap-vault step 74) instead of the unreachable in-vault path.
- **D — `sauce update --bump-pins`.** New flag rewrites consumer `ranch/platform-subscription.json` from brew-installed workshop's manifest before running the standard update. Saves manual pin-bump friction (cost felt across 4 vaults in v0.74.0 deploy).

Workshop bump 0.74.0 → 0.75.0 (MINOR). Cowork 0.13.0 → 0.14.0. New mechanism `smart-connections-bridge@0.1.0`. Engagement-types 0.2.0 → 0.3.0.

**Tech Stack:** Node.js zero-dep test harnesses (`platform/test/run-*.js`), Node CLI for sc-bridge (`@xenova/transformers` dep), Obsidian Markdown (Admonitions + tables + dataviewjs), JSON manifest files, native Claude Code tools (`Bash`, `Read`, `Write`, `Edit`).

**Spec:** `Docs/plans/2026-05-22-v0.75.0-cowork-skill-routing-hardening-design.md` (commit `ef0e8d4`).


```
X. **Re-read + structural verify.** After `write-run-note-<orch>` returns a non-`"failed:"` status:
```

```javascript
#!/usr/bin/env node
/* eslint-disable no-console */
/**
 * sc-bridge — Smart Connections semantic-retrieval bridge for Sauce.
 *
 * Reads .smart-env/multi/<sanitized>.ajson files directly + computes
 * cosine similarity using @xenova/transformers + bge-micro-v2.
 *
 * Ops: index-status | semantic-search | find-related
 *
 * Common flags: --vault <root> (required), --quiet, --json
 */
"use strict";

const fs = require("fs");
const path = require("path");

function parseArgs(argv) {
  // op = first positional; remaining = flag pairs
  const op = argv[2];
  const rest = argv.slice(3);
  const flags = { vault: null, quiet: false, topK: 3, minSimilarity: 0.45, excludeGlobs: [] };
  const positional = [];
  for (let i = 0; i < rest.length; i++) {
    const t = rest[i];
    if (t === "--vault")            flags.vault = rest[++i];
    else if (t === "--quiet")       flags.quiet = true;
    else if (t === "--json")        flags.json = true;
    else if (t === "--top-k")       flags.topK = parseInt(rest[++i], 10);
    else if (t === "--min-similarity") flags.minSimilarity = parseFloat(rest[++i]);
    else if (t === "--exclude-glob") flags.excludeGlobs.push(rest[++i]);
    else                            positional.push(t);
  }
  return { op, flags, positional };
}

function main() {
  const { op, flags, positional } = parseArgs(process.argv);
  if (!flags.vault) {
    process.stderr.write("sc-bridge: missing required --vault <root>\n");
    process.exit(2);
  }
  if (!fs.existsSync(flags.vault)) {
    process.stderr.write(`sc-bridge: vault path not found: ${flags.vault}\n`);
    process.exit(3);
  }
  switch (op) {
    case "index-status":   indexStatus(flags);                     break;
    case "semantic-search": semanticSearch(positional[0], flags);  break;
    case "find-related":   findRelated(positional[0], flags);      break;
    default:
      process.stderr.write(`sc-bridge: unknown op "${op}" (try: index-status | semantic-search | find-related)\n`);
      process.exit(2);
  }
}

// Stubs — implementations land in S6.
function indexStatus(flags)   { process.stdout.write(JSON.stringify({ index_status: "absent", vault_root: flags.vault, source_count: 0, index_age_minutes: null }) + "\n"); }
function semanticSearch(q, flags) { process.stdout.write(JSON.stringify({ index_status: "absent", query: q, hits: [] }) + "\n"); }
function findRelated(p, flags)    { process.stdout.write(JSON.stringify({ index_status: "absent", anchor: p, hits: [], skipped: "no-impl-yet" }) + "\n"); }

main();
```

```javascript
function indexStatus(flags) {
  const smartEnvDir = path.join(flags.vault, ".smart-env");
  if (!fs.existsSync(smartEnvDir)) {
    return emit({ index_status: "absent", vault_root: flags.vault, smart_env_dir: smartEnvDir, source_count: 0, index_age_minutes: null });
  }
  const multiDir = path.join(smartEnvDir, "multi");
  if (!fs.existsSync(multiDir)) {
    return emit({ index_status: "absent", vault_root: flags.vault, smart_env_dir: smartEnvDir, source_count: 0, index_age_minutes: null });
  }
  const entries = fs.readdirSync(multiDir).filter((n) => n.endsWith(".ajson"));
  if (entries.length === 0) {
    return emit({ index_status: "absent", vault_root: flags.vault, smart_env_dir: smartEnvDir, source_count: 0, index_age_minutes: null });
  }
  // Compute max mtime across all .ajson files.
  let maxMtimeMs = 0;
  for (const e of entries) {
    const stat = fs.statSync(path.join(multiDir, e));
    if (stat.mtimeMs > maxMtimeMs) maxMtimeMs = stat.mtimeMs;
  }
  const ageMin = Math.round((Date.now() - maxMtimeMs) / 60000);
  // Optional: detect stale-config by sampling first file's model key.
  let embeddingModel = null;
  let staleConfig = false;
  try {
    const smartEnvJsonPath = path.join(smartEnvDir, "smart_env.json");
    if (fs.existsSync(smartEnvJsonPath)) {
      const j = JSON.parse(fs.readFileSync(smartEnvJsonPath, "utf8"));
      embeddingModel = j?.smart_sources?.embed_model?.transformers?.model_key || null;
    }
    // Sample the first .ajson and confirm it has a vector for embeddingModel.
    const sample = fs.readFileSync(path.join(multiDir, entries[0]), "utf8");
    const parsed = parseAjsonLine(sample);
    if (embeddingModel && parsed?.embeddings && !parsed.embeddings[embeddingModel]) {
      staleConfig = true;
    }
  } catch (_) { /* defensive — fall through */ }
  emit({
    index_status: staleConfig ? "stale-config" : "ready",
    vault_root: flags.vault,
    smart_env_dir: smartEnvDir,
    embedding_model: embeddingModel,
    source_count: entries.length,
    index_max_mtime_iso: new Date(maxMtimeMs).toISOString(),
    index_age_minutes: ageMin,
  });
}

function emit(obj) {
  process.stdout.write(JSON.stringify(obj) + "\n");
  process.exit(0);
}

// Parse one .ajson line — the format is `"<key>": <value-json>` (no leading `{`).
function parseAjsonLine(text) {
  const t = text.trim();
  // Wrap in braces to make it valid JSON object literal.
  const wrapped = "{" + t + "}";
  const parsed = JSON.parse(wrapped);
  const keys = Object.keys(parsed);
  if (keys.length === 0) return null;
  return parsed[keys[0]];
}
```

```javascript
function loadModuleDirectoryMap(vaultRoot) {
  // Try ranch/platform-installed.json's blueprints[] first.
  const installedPath = path.join(vaultRoot, "ranch", "platform-installed.json");
  const map = {};
  if (fs.existsSync(installedPath)) {
    try {
      const installed = JSON.parse(fs.readFileSync(installedPath, "utf8"));
      for (const bp of (installed.blueprints || [])) {
        if (bp.id && bp.module_directory) {
          map[bp.id] = bp.module_directory;
        }
      }
    } catch (_) { /* fall through */ }
  }
  // If still empty, this bridge can't resolve placeholders — return null
  // and the caller will pass the path through verbatim (with placeholder).
  return Object.keys(map).length > 0 ? map : null;
}

function resolveModuleDirectory(rawPath, moduleDirMap) {
  if (!rawPath.includes("{{module_directory}}")) return rawPath;
  if (!moduleDirMap) return rawPath; // unresolvable — pass through
  // The SC index doesn't tag which blueprint the source came from. We need
  // a heuristic: try each known module_directory and use the first one
  // that exists as a real file. If none exist, fall back to the first
  // entry (best-effort).
  const candidates = Object.values(moduleDirMap);
  for (const md of candidates) {
    const candidate = rawPath.replace("{{module_directory}}", md);
    if (fs.existsSync(path.join(arguments[2] || ".", candidate))) {
      return candidate;
    }
  }
  return rawPath.replace("{{module_directory}}", candidates[0]);
}
```

```javascript
async function embedQuery(query) {
  const { pipeline } = require("@xenova/transformers");
  const extractor = await pipeline("feature-extraction", "Xenova/bge-micro-v2");
  const out = await extractor(query, { pooling: "mean", normalize: true });
  return Array.from(out.data); // 384-dim Float32Array → number[]
}

function cosineSim(a, b) {
  // Vectors come in normalized from BGE; dot product = cosine.
  let s = 0;
  const n = Math.min(a.length, b.length);
  for (let i = 0; i < n; i++) s += a[i] * b[i];
  return s;
}

function loadIndex(vaultRoot) {
  const multiDir = path.join(vaultRoot, ".smart-env", "multi");
  const entries = fs.readdirSync(multiDir).filter((n) => n.endsWith(".ajson"));
  const moduleDirMap = loadModuleDirectoryMap(vaultRoot);
  const sources = [];
  let parseFailures = 0;
  for (const fname of entries) {
    try {
      const txt = fs.readFileSync(path.join(multiDir, fname), "utf8");
      const parsed = parseAjsonLine(txt);
      if (!parsed) continue;
      const rawPath = parsed.path;
      const resolvedPath = resolveModuleDirectory(rawPath, moduleDirMap, vaultRoot);
      const embeddingsBag = parsed.embeddings || {};
      const modelKey = Object.keys(embeddingsBag)[0];
      const vec = embeddingsBag[modelKey]?.vec;
      if (!vec || !Array.isArray(vec)) continue;
      sources.push({ path: resolvedPath, vec });
    } catch (err) {
      parseFailures++;
      process.stderr.write(`sc-bridge: skipping unparseable .ajson ${fname}: ${err.message}\n`);
    }
  }
  // If EVERY file failed to parse, treat as error.
  if (sources.length === 0 && entries.length > 0) {
    return { sources: [], allCorrupt: true, parseFailures };
  }
  return { sources, allCorrupt: false, parseFailures };
}
```

```javascript
async function semanticSearch(query, flags) {
  if (!query) {
    process.stderr.write(`sc-bridge: semantic-search requires a query string\n`);
    process.exit(2);
  }
  const stat = indexStatusObj(flags.vault);
  if (stat.index_status === "absent") return emit({ ...stat, query, hits: [] });
  const { sources, allCorrupt } = loadIndex(flags.vault);
  if (allCorrupt) return emitError(4, { index_status: "error", error: "all-ajson-unparseable", query, hits: [] });
  let queryVec;
  try {
    queryVec = await embedQuery(query);
  } catch (err) {
    return emitError(4, { index_status: "error", error: `embed-failed: ${err.message}`, query, hits: [] });
  }
  const hits = [];
  for (const s of sources) {
    if (excludeGlobMatches(s.path, flags.excludeGlobs)) continue;
    const sim = cosineSim(queryVec, s.vec);
    if (sim < flags.minSimilarity) continue;
    hits.push({ path: s.path, similarity: sim });
  }
  hits.sort((a, b) => b.similarity - a.similarity);
  const top = hits.slice(0, flags.topK).map((h) => enrichHit(h, flags.vault));
  emit({ ...stat, query, hits: top });
}

function indexStatusObj(vaultRoot) {
  // Reuses the same logic as indexStatus() but without side-effects.
  // Inline minimal duplication for now; refactor if needed.
  const smartEnvDir = path.join(vaultRoot, ".smart-env");
  const multiDir = path.join(smartEnvDir, "multi");
  if (!fs.existsSync(smartEnvDir) || !fs.existsSync(multiDir)) {
    return { index_status: "absent", index_age_minutes: null };
  }
  const entries = fs.readdirSync(multiDir).filter((n) => n.endsWith(".ajson"));
  if (entries.length === 0) return { index_status: "absent", index_age_minutes: null };
  let maxMtimeMs = 0;
  for (const e of entries) {
    const stat = fs.statSync(path.join(multiDir, e));
    if (stat.mtimeMs > maxMtimeMs) maxMtimeMs = stat.mtimeMs;
  }
  return { index_status: "ready", index_age_minutes: Math.round((Date.now() - maxMtimeMs) / 60000) };
}

function excludeGlobMatches(p, globs) {
  // Minimal glob: support "**" and "*" prefix/suffix.
  for (const g of (globs || [])) {
    const re = new RegExp("^" + g.replace(/[.+?^${}()|[\]\\]/g, "\\$&").replace(/\*\*/g, ".*").replace(/\*/g, "[^/]*") + "$");
    if (re.test(p)) return true;
  }
  return false;
}

function enrichHit(hit, vaultRoot) {
  // Pull title (basename minus .md) + 200-char snippet.
  const abs = path.join(vaultRoot, hit.path);
  let title = path.basename(hit.path).replace(/\.md$/, "");
  let snippet = "";
  try {
    const body = fs.readFileSync(abs, "utf8");
    // Strip leading frontmatter if present.
    const stripped = body.replace(/^---\n[\s\S]*?\n---\n/, "");
    snippet = stripped.replace(/\s+/g, " ").trim().slice(0, 200);
    // First markdown heading (#-prefix) wins as title.
    const headingMatch = stripped.match(/^#\s+(.+)$/m);
    if (headingMatch) title = headingMatch[1].trim();
  } catch (_) { /* fall through with defaults */ }
  return { path: hit.path, title, similarity: hit.similarity, snippet };
}

function emitError(code, obj) {
  process.stdout.write(JSON.stringify(obj) + "\n");
  process.exit(code);
}
```

```javascript
let passed = 0, failed = 0;
function assertTrue(c, msg) { if (!c) { failed++; console.error(`FAIL ${msg}`); } else passed++; }
function assertEq(actual, expected, msg) {
  if (actual !== expected) { failed++; console.error(`FAIL ${msg} -- expected ${JSON.stringify(expected)}, got ${JSON.stringify(actual)}`); }
  else passed++;
}

function runBridge(args) {
  try {
    const out = execFileSync("node", [BRIDGE, ...args], { encoding: "utf8" });
    return { code: 0, stdout: out, stderr: "" };
  } catch (err) {
    return { code: err.status, stdout: err.stdout?.toString() || "", stderr: err.stderr?.toString() || "" };
  }
}
```

```javascript
// platform/cli/cmd-update.js — add the bump-pins handler + wire into argv parsing
function handleBumpPins({ keepComparators, dryRun }) {
  const cwd = process.cwd();
  const subscriptionPath = path.join(cwd, "ranch", "platform-subscription.json");
  if (!fs.existsSync(subscriptionPath)) {
    process.stderr.write("sauce: --bump-pins requires a consumer vault; cwd must contain ranch/platform-subscription.json\n");
    process.exit(2);
  }
  const installedPath = path.join(cwd, "ranch", "platform-installed.json");
  if (!fs.existsSync(installedPath)) {
    process.stderr.write("sauce: ranch/platform-installed.json missing; run sauce install first\n");
    process.exit(3);
  }
  const installed = JSON.parse(fs.readFileSync(installedPath, "utf8"));
  const workshopManifestPath = path.join(installed.workshop_path, "platform", "manifest.json");
  if (!fs.existsSync(workshopManifestPath)) {
    process.stderr.write(`sauce: workshop manifest not parseable at ${workshopManifestPath}\n`);
    process.exit(4);
  }
  const workshopManifest = JSON.parse(fs.readFileSync(workshopManifestPath, "utf8"));
  const subscription = JSON.parse(fs.readFileSync(subscriptionPath, "utf8"));

  const newSubscription = JSON.parse(JSON.stringify(subscription)); // deep clone
  const diff = [];

  // Top-level workshop_version
  if (newSubscription.workshop_version !== workshopManifest.workshop_version) {
    diff.push(`  workshop_version: ${newSubscription.workshop_version} -> ${workshopManifest.workshop_version}`);
    newSubscription.workshop_version = workshopManifest.workshop_version;
  }

  // Blueprint pins
  const bpManifestMap = {};
  for (const bp of (workshopManifest.blueprints || [])) bpManifestMap[bp.id] = bp.version;
  for (const pin of (newSubscription.pinned?.blueprints || [])) {
    const wsVer = bpManifestMap[pin.id];
    if (!wsVer) {
      diff.push(`  pinned.blueprints.${pin.id}: WARNING — not in workshop manifest, leaving at ${pin.version}`);
      continue;
    }
    const newPin = keepComparators
      ? pin.version.replace(/[\d.]+$/, wsVer)
      : wsVer;
    if (pin.version !== newPin) {
      diff.push(`  pinned.blueprints.${pin.id}: ${pin.version} -> ${newPin}`);
      pin.version = newPin;
    }
  }

  // Mechanism pins
  const mechManifestMap = {};
  for (const m of (workshopManifest.mechanisms || [])) mechManifestMap[m.id] = m.version;
  for (const pin of (newSubscription.pinned?.mechanisms || [])) {
    const wsVer = mechManifestMap[pin.id];
    if (!wsVer) {
      diff.push(`  pinned.mechanisms.${pin.id}: WARNING — not in workshop manifest, leaving at ${pin.version}`);
      continue;
    }
    const newPin = keepComparators
      ? pin.version.replace(/[\d.]+$/, wsVer)
      : wsVer;
    if (pin.version !== newPin) {
      diff.push(`  pinned.mechanisms.${pin.id}: ${pin.version} -> ${newPin}`);
      pin.version = newPin;
    }
  }

  // New-in-workshop items not in subscription — note but don't add.
  const subscribedBp = new Set((newSubscription.pinned?.blueprints || []).map((p) => p.id));
  for (const bp of (workshopManifest.blueprints || [])) {
    if (!subscribedBp.has(bp.id)) diff.push(`  pinned.blueprints.${bp.id}: (new in workshop — not subscribed, skipped)`);
  }
  const subscribedMech = new Set((newSubscription.pinned?.mechanisms || []).map((p) => p.id));
  for (const m of (workshopManifest.mechanisms || [])) {
    if (!subscribedMech.has(m.id)) diff.push(`  pinned.mechanisms.${m.id}: (new in workshop — not subscribed, skipped)`);
  }

  if (diff.length === 0) {
    process.stdout.write("sauce: subscription pins already match workshop; nothing to bump.\n");
    return;
  }
  process.stdout.write(`sauce: bumping subscription pins from workshop manifest at ${workshopManifestPath}\n`);
  for (const line of diff) process.stdout.write(line + "\n");

  if (dryRun) {
    process.stdout.write("sauce: --dry-run set; subscription NOT written.\n");
    return;
  }
  fs.writeFileSync(subscriptionPath, JSON.stringify(newSubscription, null, 2) + "\n");
  process.stdout.write("sauce: subscription updated; running standard sauce update flow.\n");
}
```

## Notes for the implementer

- **Multi-session execution OK.** Per `Docs/plans/2026-05-22-v0.75.0-handoff.md` convention from v0.71/74, write a handoff stub at each session-end documenting which step is in-progress.
- **Stage ordering matters but is recoverable.** S1 (Layer 1) committing before S2 (Layer 2) temporarily diverges orchestrators from their write-run-note contracts; this is documented in the design's Open Questions §6. Land both stages in the same cycle.
- **Bridge cold-load latency.** During S6 smoke, the first `semantic-search` call pulls bge-micro-v2 weights from huggingface (~25MB; one-time). Subsequent runs cache. If S6 testing on a fresh machine, allow ~10s for the first run.
- **Subagent dispatch.** When using `superpowers:subagent-driven-development`, dispatch ONE subagent per stage (not per step). Per-subagent stage takes ~5-30 minutes depending on stage complexity. S6 (bridge implementation) is the heaviest single subagent task; consider breaking into two subagents (one for index-status + helper functions, one for semantic-search + find-related) if context-window pressure is real.
- **What can be parallel?** Stages S1 (Layer 1 rewrites) and S5 (sc-bridge scaffold) touch different files and could run in parallel subagents. Stages S6 + S8 cannot — S8 references sc-bridge from the gather sub-skill. Stages S9 + S12 + S13 touch independent surfaces. The integration tests in S4, S7, S14 must follow their corresponding feature stages.
