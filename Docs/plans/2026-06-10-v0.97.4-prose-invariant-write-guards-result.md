# v0.97.4 prose-invariant write-guards — result

## TL;DR

Closes three prose-level invariant gaps the v0.97.3 cloud-sync-parity ship left visible in today's accuris morning briefing: missing rating callout, missing anti-echo callout, and silent priority-loop incompleteness. All three now have deterministic backstops inside `write-atomic-note-helper.js`. The rating + anti-echo guards hard-fail when violated (no file gets written). The coverage-gap guard injects a `> [!warning]+ Coverage gap` callout BEFORE the first per-kind block AND mirrors `coverage_gap: { expected, surfaced, skipped }` into the sidecar — non-failing, but the gap is now VISIBLE to the user AND machine-readable for cross-day reconciler analysis.

Plus the gather-from-served-by SKILL.md gains a new `## Microscope output-shape contract (INLINE — do not delegate to a separate read)` section. Four mandatory structural elements (Utilization snapshot + urgency tiers + inner-circle wikilinks + calendar markdown table) + verbal-commitment line + pre-render self-check checklist + flat-list-fallback prohibition. The LLM under wrapper-load was silently skipping the microscope-file read; the inline contract removes that load-bearing dependency on a separate file open.

Architectural shift: where v0.97.3 made the SHAPE of the brief contractually correct, v0.97.4 makes the BEHAVIOR of the brief contractually correct. Prose-level invariants the LLM owns now have deterministic backstops that fail the write — not just structural checks the regex re-read pass could catch.

## Lessons captured

- **Deterministic backstops must cover both shape AND behavior.** v0.97.3's regex/sidecar-schema backstops caught structural drift but couldn't see prose-level invariants. v0.97.4 closes that gap by letting writeAtomicNote ITSELF refuse the write when an invariant is violated.
- **Visibility beats silent dropping.** The coverage-gap guard does NOT fail the write — some priority kinds legitimately have no data on a given day. But it makes the gap LOUD in the rendered brief (warning callout at top) AND machine-readable in the sidecar. A user staring at a fire that emitted 3 callouts when they configured 5 priorities will now SEE the warning, not silently wonder why two were missing.
- **Inline the contract when the LLM is under wrapper-load.** The microscope output-shape contract used to live behind a "READ this file" delegation. Under load, the LLM was skipping the read. Inlining the four mandatory elements into the SKILL body that's always loaded as wrapper context removes the load-bearing dependency on a separate file open. Same fix pattern as v0.97.2's inline write contract.
- **HC tests as forensic instruments.** HC-V0974-PD-1..5 were written to "prove or disprove the planDispatch filtering bug." They proved the helper contract is correct, redirecting the cycle to the right fix (coverage-gap write-guard) instead of chasing a phantom bug in dispatch.
