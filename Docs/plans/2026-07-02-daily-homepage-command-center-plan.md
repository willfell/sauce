## Literal contracts (quote, don't paraphrase)

Existing, verified:
- `SpaceDailyDashboard.selectTasks(dv, todayStr, TE)` → `{ open: page[], done: number, overdue: number }` (open = today only; overdue/done = counts). Cold load (no TE) → `{ open: [], done: 0, overdue: 0 }`.
- Render closure today: `const getMeetings = () => { … dv.pages("spice/meetings/notes").where(p => p.file.name.includes(today)).sort(p => p.file.name, "asc"); return pages.array(); }`.
- `TaskDialog.prototype._create(app, payload, notes)` — composes via `TaskEntity` (`composeNote` defaults `type:'task'`, `status: payload.status || 'open'`), dedupes filename via `TE._uniqueName`, `await app.vault.create('spice/tasks/'+finalName, content)`. Payload fields it reads: `title, scheduled, due, priority, source, source_note, links, project`.
- `SpaceHome._greeting(hour)` / `_humanDate(iso, todayIso)` are pure; `_captureSpec()` returns `[{key,label,icon}]`; `render(dv, params)` reads the clock only via `moment()`.
- `SpaceHome._dispatch(key, dv, today)` grabs `customJS`/`app` from runtime globals with guards.

## Stage 2 — TaskDialog.createQuick
File: `platform/mechanisms/task-entity/task-dialog.js`
1. Add instance method:
   ```
   async createQuick(opts) {
     const app = (typeof window !== 'undefined' && window.app) || (typeof app !== 'undefined' ? app : null);
     const title = String((opts && opts.title) || '').trim();
     if (!app || !title) return;
     const payload = { title, scheduled: (opts && opts.today) || '', source: (opts && opts.source) || 'daily', links: [] };
     await this._create(app, payload, '');
   }
   ```
   (match the file's existing global-grab idiom + brace style.)

## Stage 3 — SpaceHome glance + inline capture
Files: `platform/blueprints/home/helpers/space-home.js`, `platform/blueprints/home/helpers/sauce-home.css`
1. `static _glanceChips(counts)` (pure): input `{today,overdue,done,meetings}` (coerce to ints, default 0). If all 0 → `{ empty: true, text: 'Clear day — nothing scheduled' }` (or a sentinel the render checks). Else → `{ empty:false, chips:[…] }` where chips include only `>0` counts, in order today/overdue/meetings/done, each `{ n, label, cls }`: today→`label 'today'`; overdue→`'overdue'`,`cls:'sauce-section-overdue-pill'`; meetings→`n===1?'meeting':'meetings'`; done→`'done'`. Keep the shape Node-assertable.
2. `render(dv, params)`:
   - Keep `_greeting` + `_humanDate` lines.
   - After the date, derive counts (guarded): `const SDD = customJS && customJS.SpaceDailyDashboard; const TE = customJS && customJS.TaskEntity; const counts = (SDD && typeof SDD.computeCounts==='function') ? SDD.computeCounts(dv, today, TE) : {today:0,overdue:0,done:0,meetings:0};` then build `.sauce-home-glance` from `_glanceChips(counts)`.
   - Capture band: FIRST child = a capture row `.sauce-home-capture-input-row` holding `<input type="text" class="sauce-home-capture-input" placeholder="Jot a task…">` + an `Add` button `.sauce-home-capture-add`. Wire: Enter keydown on input, and Add click → `const text = input.value; if (String(text).trim()) { const td = customJS && customJS.TaskDialog; if (td && typeof td.createQuick==='function') { await td.createQuick({ title: text, today, source: 'daily' }); } await self.render(dv, params); }` (capture `const self = this;` at top). No autofocus.
   - Then the 3 buttons from `_captureSpec()` (now meeting/scratch/openDaily), wired via `_dispatch` unchanged.
