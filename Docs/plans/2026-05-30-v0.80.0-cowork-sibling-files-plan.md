# v0.80.0 — cowork-sibling-files (implementation plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the v0.79.0 `user-supplied` resolution path placeholder by making per-kind sibling files (`spice/cowork/prompts/per-mcp/<kind>/*.md` excluding `microscope.md` and `_*.md`) a real, USER-owned context surface that the 5 atomic-note orchestrators discover + read, `cowork:gather-from-served-by` injects verbatim into the dispatch contract, and `cowork:edit-microscope` scaffolds inline when the user-supplied gap surfaces.

**Architecture:** Strict-additive on top of v0.79.0. (A) Orchestrators gain step 2c (mirrors v0.79.0 step 2b microscope read): glob `per-mcp/<kind>/*.md`, exclude `microscope.md` + `_*.md`, build `siblings[kind] = [{name, body}, ...]`. (B) `gather-from-served-by` accepts a new `siblings[]` input, injects each entry verbatim under `**User-supplied reference: <name>**` blocks in dispatch contract Step 3 (after `what_matters`, before `**Hard rules ...**`), echoes back `siblings_used[]`. (C) `edit-microscope` step 4 user-supplied branch pre-checks existence via `mcp__obsidian__get_file_contents`, scaffolds via new `composeSibling` helper (deterministic, gap-text-keyed column heuristic), writes the sibling, records a reference entry that lands in `microscope.md`'s `## References` section (via extended `composeMicroscope`). No microscope + no siblings + no hard_rules ⇒ byte-clean v0.79.x behavior.

**Tech Stack:** Node 20+ (workshop helpers); Claude Code skill bodies (markdown SKILL.md); workshop harness `platform/test/run-cowork-smoke.js` (+ `run-install.js` for preservation).

**Spec:** `Docs/plans/2026-05-30-v0.80.0-cowork-sibling-files-design.md` (commit `fff789c`).

const COLUMN_HEURISTICS = [
    { rx: /vip|priority/i,        cols: ["id", "reason"] },
    { rx: /phone|number/i,        cols: ["phone", "name"] },
    { rx: /email/i,               cols: ["email", "name"] },
    { rx: /account|\bid\b|alias/i, cols: ["id", "nickname"] },
];

function _inferColumns(gap) {
    const text = String(gap || "");
    for (const h of COLUMN_HEURISTICS) {
        if (h.rx.test(text)) return h.cols;
    }
    return ["key", "value"];
}

function composeSibling({ kind_name, gap, suggested_name }) {
    const name = String(suggested_name || "").trim() || "reference.md";
    const cols = _inferColumns(gap);
    const headerRow = `| ${cols.join(" | ")} |`;
    const sepRow = `|${cols.map(() => "---").join("|")}|`;
    const titleSlug = name.replace(/\.md$/i, "").replace(/[-_]+/g, " ").replace(/\b\w/g, c => c.toUpperCase());
    const body = [
        `# ${titleSlug}`,
        "",
        `<!-- USER-OWNED sibling file for kind "${kind_name}". Authored via cowork:edit-microscope. Never overwritten by sauce update/reinstall. -->`,
        "",
        `_What this file is for_: ${gap ? String(gap).trim() : "(describe how the gather should use this reference)"}`,
        "",
        headerRow,
        sepRow,
        `| | |`,
        "",
    ].join("\n");
    return { name, body, status: "ok" };
}
