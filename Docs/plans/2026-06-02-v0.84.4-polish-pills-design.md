# v0.84.4 polish-pills — design

Three CSS-only polish tweaks on top of v0.84.3's right-aligned section-header pills, surfaced by post-deploy review of the workshop dashboard in Obsidian:

1. **§1 Pills hug chevron.** v0.84.3's `.sauce-section-counts` and the pre-existing `.sauce-section-chevron` both carry `margin-left: auto`. Two flex siblings with auto-margins split the available free space equally — counts ends up roughly centered, with visually-broken whitespace between counts and chevron. Fix: suppress the chevron's auto-margin when a counts span precedes it via the adjacent-sibling selector. Sections without `rightHtml` (none today; future-safe) still get the original chevron-pushes-right behavior.

2. **§2 More breath between Open and Done.** `.sauce-section-counts { gap: 6px }` → `gap: 10px`. ~60% more breathing room between the orange and green Tasks pills. Mobile-pass `gap: 4px` unchanged.

3. **§3 Findable border on Meetings/Activity count pill.** `.sauce-section-count-pill`'s `border: 1px solid var(--background-modifier-border)` resolves to near-transparent in the active theme; the user reported the pill looked like plain muted text. Switch to `var(--background-modifier-border-hover)` — same role-based variable family, one notch more contrast. The pill becomes findable without competing with the colorful Tasks pills.

No JS changes. No new CSS classes. No callers touched. Pure CSS adjustment of existing v0.84.3 rules.

## CSS edits in detail

### §1 — Sibling-selector to disable chevron auto-margin

Add a new rule near `.sauce-section-chevron`'s existing block:

```css
.space-daily-dashboard .sauce-section-counts + .sauce-section-chevron {
  margin-left: 0;
}
```

The parent's `gap: 8px` still applies between counts and chevron, giving the "little bit of a gap" the user asked for. The existing `.sauce-section-chevron { margin-left: auto; }` rule stays — it's still the correct fallback for any future caller that omits `rightHtml`.

### §2 — Container gap

```css
.space-daily-dashboard .sauce-section-counts {
  ...
  gap: 10px;  /* v0.84.4: was 6px; more breathing room between Open and Done */
}
```

### §3 — Count-pill border visibility

```css
.space-daily-dashboard .sauce-section-count-pill {
  ...
  border: 1px solid var(--background-modifier-border-hover);  /* v0.84.4: was --background-modifier-border (near-transparent in dark themes) */
}
```

## Risk register

| Risk | Mitigation |
| --- | --- |
| Adjacent-sibling selector `+` not supported | Universal in modern browsers including Electron-based Obsidian. Safe. |
| `--background-modifier-border-hover` not defined in some user themes | Falls back to browser default (typically `currentColor`) which would render a muted gray border — acceptable degradation. Most Obsidian themes define both `--background-modifier-border` and the `-hover` variant. |
| `gap: 10px` makes Tasks header overflow on mobile | Mobile-pass `gap: 4px` override still applies via `@media (max-width: 480px)`. No regression. |
