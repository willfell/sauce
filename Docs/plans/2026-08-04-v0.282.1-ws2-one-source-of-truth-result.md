## Regression caught at verification (fixed in-cycle)

The eager `module.exports.topology = require(...)` in `delivery/index.js` (Task 2) broke `OperatorStation._deliveryApi()`'s installed-artifact fallback: that loader evaluates the installed `index.js` in a sandbox whose `require` stub supports only `./scripts/delivery-contract`, so the index threw and consumer vaults would have degraded to the recovery state on that path (pinned by `OPX3-CORE-INSTALLED-ARTIFACT`). Fixed by making `topology` a lazy getter — restricted loaders keep the pure contract; Node consumers resolve on first access (`fix(delivery): lazy topology export…`).

**Lesson (evidence discipline):** the failure was initially masked by piping preflight through `tail -N` — the pipeline exit code was tail's, so a red suite read as green. Capture the suite's own exit code (`npm run release:preflight > log 2>&1; echo $?`), never a pipeline tail's.
