# Implementation plan — finance v0.10.0 planning layer

**Execution discipline (landmine #27):** build in the order S1→S6. Each stage has a GATE (a specific command that must exit green) before the next stage starts. Coupled work is sequential; never preflight-at-the-end as the first verification.

**Conventions:** instance methods only (customjs static-on-instance trap, landmine #28). JSON not YAML for manifest. All widget invocations via `dv.view("ranch/views/customjs-guard", { class })`. Migrations: `adapter.read`/`write` + regex/YAML, marker-guarded, `.sauce-backup/<ts>/` per write (band-injectors only; scaffolders are create-if-absent, no snapshot), per-file failure-loud. No `Co-Authored-By: Claude` trailer on commits.

## S1 — FinanceMath engine + behavioral harness

**Files:** `platform/blueprints/finance/helpers/finance-math.js` (extend), `platform/test/run-finance-plan-state.js` (new), `package.json` (register harness).

1. Add instance methods to `FinanceMath` (after the existing methods, before the closing brace):
   - `readPlan(dv)` → `dv.pages('"spice/finance"').where(p => p && p.type === "finance-plan").array()[0] || null` (try/catch → null).
   - `readSavings(dv)` → `dv.pages('"spice/finance/savings"').where(p => p && p.type === "savings-account").array()` (try/catch → []).
   - `glide(balance, tiers)` → iterate `tiers`; first tier with `under > balance` wins (`contribution = tier.monthly`, `tier = idx+1`); else the `at_or_above` tier; default `{tier:1, contribution:0}` when tiers empty.
   - `simulateAvalanche(debts, attackTotal, opts)` → month-by-month sim: each active debt accrues `balance += balance*apr/1200`, pays `min(min_payment, balance)`; the target (resolved by APR desc + optional override) gets `attackTotal` on top; roll on zero; record `killOrder[{debt,date}]` + `months`; cap 600 iters; non-converge → `{months: Infinity, zeroDebtDate: "—", killOrder}`. Date math: clone `new Date()`, `setMonth(+months)`, `.toISOString().slice(0,10)`.
   - `computePlanState(dv, monthKey)` → the §4 object. Order: readPlan (→ `ok:false,reason:"no-plan"` if null); read debts/savings/paychecks(month)/budget(month); compute minimums, glide, freed, attack, envelope.base; overageCarry from prior month budget; allocation (avalanche + override + roll); payoff via simulateAvalanche; overflow (income>floor); whatIf (sim with month-1 attack 0); applyPlan. Use existing `fmtMoney`/`_coerceMonthString`/`monthIncome`/`monthSpending`. **All internal self-calls use `this.X(...)`.**
2. Write `platform/test/run-finance-plan-state.js`: load finance-math.js into a sandbox (mirror `run-v01103-monthly-overview.js` setup — `new Function` + stub `dv` with a `pages()` returning a `.where().array()`-capable shim). Assert families `HC-V0128-PLANSTATE-*`:
   - envelope base = 2949 on the headspace fixture (floor 9000, fixed 3851, 4 debts mins 1330, attack 570, savings 639.94→tier1 300).
   - tier boundaries: balance 1499→tier1/300; 1500→tier2/150 + freed 150 + attack 720 + envelope STILL 2949; 3500→tier3/0 + freed 300 + attack 870 + envelope 2949.
   - allocation: target = highest-APR active (Cap1 Platinum) gets min+attack; others min only; `attack_target_override` (Apple until <13950) overrides target while Apple ≥ 13950; roll: set Cap1 balance 0 → target becomes Discover.
   - underwater: planned 3120 > effective 2949 → `over:171`, `status:"over"`.
   - overflow: income 10000 > floor 9000 → surplus 1000, toAttack 800, toFlex 200.
   - whatIf: `skipAttackThisMonth.weeksSlipped` > 0 and finite.
   - degrade: no-plan → ok:false; no-debts → allocation [] + payoff "—"; income_floor 0 → over suppressed.
3. Register in `package.json` `release:preflight` (line 35): append ` && node platform/test/run-finance-plan-state.js` to the chain. Add `"test:finance-plan-state": "node platform/test/run-finance-plan-state.js"` shorthand.

**GATE S1:** `node platform/test/run-finance-plan-state.js` → all PASS, 0 FAIL.
