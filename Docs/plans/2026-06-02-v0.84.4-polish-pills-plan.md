### Task 1: CSS edits (canonical)

Edit `platform/blueprints/daily/helpers/sauce-daily-dashboard.css`:

**Edit A — add sibling-selector rule.** After the existing `.sauce-section-chevron > details[open] > .sauce-section-summary .sauce-section-chevron { transform: rotate(90deg); }` block (around line 61), insert:

```css
/* v0.13.4 (sauce v0.84.4): when a counts span precedes the chevron, suppress
 * the chevron's auto-margin so counts hugs the right edge. The original
 * margin-left:auto rule above is still the correct fallback for any future
 * caller that omits rightHtml. */
.space-daily-dashboard .sauce-section-counts + .sauce-section-chevron {
  margin-left: 0;
}
```

**Edit B — `.sauce-section-counts` gap.** Change `gap: 6px;` to `gap: 10px;`.

**Edit C — `.sauce-section-count-pill` border.** Change `border: 1px solid var(--background-modifier-border);` to `border: 1px solid var(--background-modifier-border-hover);`.
