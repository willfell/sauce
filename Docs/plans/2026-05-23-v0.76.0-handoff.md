## What shipped (one-paragraph summary)

v0.76.0 bundles four v0.75.1 carry-forward bug fixes with the first
half of cowork's interactive-context personalization feature.
Workstreams A + B fix `_resolveWorkshopPath` (the ancestry walk now
anchors on `__filename`, not `process.execPath`; stale stored
`workshop_path` values are invalidated via a `platform/manifest.json`
probe). Workstream C mirrors v0.75.1's H morning-briefing fix on
eod-review + weekly-review (semantic-warning gated on the gather step
having run + canonical text from gather-semantic-related). Workstream D
adds explicit engagement-template prompt fallback to eod/weekly/monthly
orchestrators when the user prompt is empty. Workstream E adds
regression coverage for v0.59.9's `materialize_once` flag (no
implementation change needed — the existing flag was discovered during
writing-plans and reused). Workstream F ships
`cowork:context-builder` — a new orchestrator-tier skill with 14
hand-curated questions across 4 MCP-kinds (calendar, gmail, imessage,
finance), writing structured preferences into the new user-owned
`spice/cowork/context/user-preferences.md`. Workstream G ships
`Docs/agent-guides/cowork-customization-contract.md`, the STOCK vs USER
boundary contract (including a third USER-DRAFTABLE WITH BACKUP
category for the 5 cowork prompts). Workstream H wires
`cowork:onboard-scheduled-jobs` to auto-delegate to context-builder
when user-preferences is absent or seed-stamped — realizing the user's
"all in one skill invoke" requirement. 16 new harness cases. v0.77.0
will wire the 5 atomic-note orchestrators to consume
user-preferences.md.

Cowork 0.14.1 → 0.15.0. Workshop 0.75.1 → 0.76.0.
smart-connections-bridge unchanged at 0.1.1. Engagement-types unchanged
at 0.3.1.
