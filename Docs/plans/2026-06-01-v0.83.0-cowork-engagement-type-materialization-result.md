## NEW lessons surfaced

### 1. Plan replacement-text consistency check

S3's plan-spec replacement text for `eod-review`, `weekly-review`, and `monthly-review` `SKILL.md` Step 2 omitted the `If not found, exit silently.` guard that `midday-tripwire` and `morning-briefing` already had in their baseline. The omission was caught mid-cycle and folded into S4 (S4.FIX). **Lesson:** when writing plan-spec replacement text that touches multiple orchestrators with similar but not identical baselines, diff the relevant pre-edit prose across all orchestrators FIRST and ensure the replacements preserve every existing safety guard. This is especially important when copying from a "canonical" orchestrator — the others may have subtly different guard phrases.

### 2. Plan-inherited Notice gap

S4's plan for `bootstrap-vault` step 8 described "treat dir-not-found as fatal" in the prose but only provided explicit `cowork:<orch> aborted -- <reason>` Notice text for the dir-empty case. The dir-not-found failure path had no explicit text, so S4.2 added it. **Lesson:** when an orchestrator step has multiple failure paths (dir-not-found vs. dir-empty vs. malformed-file), every failure path needs its own explicit Notice text in the plan spec. Do not rely on implication — if the text is not there, it will not be written.

### 3. Test-fixture obsolescence at surface change

S4 surfaced 2 legacy HC-V0750-C1 and HC-V0750-C3 assertions that positively-asserted pre-v0.83.0 surface contracts that S4 removed (onboard-scheduled-jobs previously reading from an older path). These fixtures had been green for multiple cycles and would have flipped to false-pass after S4 without the S4.1 correction. **Lesson:** cycles that remove or replace a surface contract should grep for positive-assertion fixtures matching the old contract BEFORE S0 close, not at preflight failure time. A pre-S0 grep for the old path string in the harness files would have caught this in advance.
