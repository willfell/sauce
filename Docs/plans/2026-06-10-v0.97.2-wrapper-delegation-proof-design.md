# v0.97.2 wrapper-delegation-proof — design

> [!info]+ Status
> AUTO-EXECUTE authorized per user instruction "go through, deploy, push your changes". Direct-push to main, no PRs (sauce workshop convention). Push gated to S5 with explicit user approval. SHIPPED 2026-06-10.

## 0. Origin

The v0.97.1 cycle shipped Rail A's sync orchestrator pushing inlined orchestrator-instructions bodies as wrapper prompts to claude.ai's scheduled tasks via `update_scheduled_task` MCP. That mechanism worked.

This morning (2026-06-10), accuris's morning-briefing fire produced structurally-wrong output:

- Wrote `spice/cowork/daily/2026/06-June/Tuesday-2026-06-10.md` instead of `2026-06-10/morning-briefing.md` (daily-blueprint pattern, NOT cowork atomic-note pattern)
- Said "Tuesday" in the title but it was a Wednesday (verbatim copy of `e.g. "Tuesday"` example value from the PRELUDE)
- Used `type: cowork-daily-note` instead of `cowork-morning-briefing`
- Skipped callout structure entirely (plain `## Headings` instead of `[!example]+`/`[!warning]+`/`[!info]+` callouts)
- Wrote a fabricated 5-field sidecar with `cadence: "morning"` instead of `type: cowork-morning-briefing`

Headspace's morning-briefing at the same fire-time was structurally perfect — same wrapper, same architecture, same contract — different LLM behavioral choice. Headspace executed the orchestrator inline. Accuris delegated to a Task() subagent mid-orchestration: *"I'll delegate this to a specialized agent to handle the full morning briefing workflow."* The subagent then improvised everything.

The wrapper architecture itself was fine. The contract was fine. The problem was that nothing in the wrapper PROHIBITED delegation, and one engagement's LLM made the wrong choice. v0.97.2 closes that hole.

## 1. Scope

### 1.1 What ships

- **Anti-delegation directive** prepended to every composed wrapper, ahead of the PRELUDE, banning Task()/Agent() invocations.
- **Inline write contract** — Step 7 in all 5 atomic-note orchestrator-instructions files (morning-briefing, midday-tripwire, eod-review, weekly-review, monthly-review) is rewritten from "READ `<vault>/.claude/skills/cowork/skills/write-run-note-<cadence>/SKILL.md` ... follow its Steps section" (delegation pattern) to a 5-substep inline contract (7a path / 7b frontmatter YAML / 7c DataviewJS / 7d callout body skeleton / 7e obsidian_put_content invocation).
- **Date-PRELUDE fix** — the helper's PRELUDE block hardcoded example values (`e.g. "Tuesday"`, `e.g. "June"`) that the accuris LLM literally copied into its title. New PRELUDE drives the LLM at Bash `date` commands with timezone, plus the verbatim instruction `do NOT use any example value`.

### 1.2 What does NOT ship

- Removing the write-run-note-<cadence> SKILL.md files themselves — kept as legacy/manual-invocation paths (e.g., for `sauce reconcile-cowork --dry-run` local invocation against the helper). Orchestrator-instructions just stop DELEGATING to them.
- Touching `scheduled-job-contract.json` — the contract shape didn't change, only the per-cadence orchestrator-instructions bodies + helper PRELUDE. `contract_version` stays 0.35.1.
- Touching the v0.97.1 reconciler cadence — it's not an atomic-note write, doesn't have a Step 7 contract issue. (But still gets the anti-delegation directive at compose time, via the shared helper.)
- v0.97.1 launchd grace removal — still queued for v0.98.0+.

## 2. Architecture overview

### 2.1 Cycle identity

- **Workshop:** 0.97.1 → **0.97.2** PATCH
- **Cowork blueprint:** 0.35.1 → **0.35.2** PATCH
- **scheduled-job-contract.json `contract_version`:** **UNCHANGED at 0.35.1** (the contract shape didn't change — landmine #20 lockstep does NOT trigger when the contract data is byte-identical pre/post-cycle)
- **Mechanism count:** unchanged (17)
- **Codename:** `wrapper-delegation-proof`

### 2.2 Why a behavioral fix lives in the wrapper, not the orchestrator

The wrapper is the only artifact the cron LLM reads when a scheduled task fires. The orchestrator-instructions file lives at `spice/cowork/data/orchestrator-instructions/<cadence>.md` on disk — the cron LLM does NOT read that file at fire time; the helper inlined its body into the wrapper at sync time. So:

- Anti-delegation directive must live at the TOP of the COMPOSED WRAPPER (helper change).
- Inline write contract must live INSIDE the orchestrator-instructions body (so it gets inlined at sync time — orchestrator-instructions changes).
- PRELUDE date fix must live in the helper's PRELUDE composition (helper change).

### 2.3 The three knobs

1. **Knob A — anti-delegation directive** (helper change):

    Prepended as the first non-blank paragraph to every wrapper body, ahead of the `You are running cowork:<cadence>` introduction. Reads:

    ```
    ANTI-DELEGATION (NON-NEGOTIABLE): You are running this entire orchestrator
    INLINE in the current context. DO NOT spawn subagents. DO NOT use Task(),
    Agent(), or any agent-launching tool. DO NOT summarize the work and hand
    it off. Every step below — including the per-kind gather loops — executes
    in THIS turn. If the wrapper feels long, that is intentional; follow it
    step-by-step rather than delegating. A delegated run produces structurally-
    wrong output (wrong path, wrong frontmatter type, missing callout
    structure, missing sidecar, missing rating block) and is treated as a
    failed fire.
    ```

    Coverage: all 6 cadences (morning-briefing, midday-tripwire, eod-review, weekly-review, monthly-review, reconcile-cowork). The directive lives in `compose-scheduled-job-wrappers-helper.js` around the wrapper-construction block (~line 593).

2. **Knob B — inline write contract** (orchestrator-instructions change × 5):

    Replaces Step 7 in all 5 atomic-note orchestrator-instructions files. The new Step 7 has 5 sub-steps:

    - **7a** — compute the EXACT output path: `spice/cowork/daily/{{$today_dirpath}}/{{$cadence}}.md`. Spells out the forbidden daily-blueprint shape (`Tuesday-2026-06-10.md`) explicitly so the LLM cannot confuse the two.
    - **7b** — emit the frontmatter as a literal YAML block. Spells out the FORBIDDEN keys list: `cadence`, `date`, `engagement` (NOT engagement_id), `generated_at`, `week`, `month`, `year`, `schema_version`.
    - **7c** — emit the DataviewJS SpaceNavButtons block as the literal first body content.
    - **7d** — body skeleton with hard rule that every per-kind block MUST be a Callout, NEVER a plain `## Heading`.
    - **7e** — invoke `mcp__<vault>-obsidian__obsidian_put_content` with the resolved path + body content. On error, emit Notice and exit non-zero (do NOT fall back to a different path).

    Coverage: morning-briefing.md, midday-tripwire.md, eod-review.md, weekly-review.md, monthly-review.md.

    The previous Step 7c was `READ <vault>/.claude/skills/cowork/skills/write-run-note-<cadence>/SKILL.md ... follow its Steps section`. That READ-then-follow delegation pattern was the structural opening for the cron LLM to interpret "follow its Steps" as "launch an agent to execute those Steps" — which is what accuris did.

3. **Knob C — PRELUDE date fix** (helper change):

    The old PRELUDE block hardcoded example values:

    ```
    today_weekday  = e.g. "Tuesday"
    today_month_name = e.g. "June"
    today_day      = e.g. "9" (no leading zero)
    today_year     = e.g. "2026"
    ```

    The accuris LLM literally copied "Tuesday" into the morning-briefing title on a Wednesday. The new PRELUDE drives the LLM at Bash `date` commands with timezone explicit:

    ```
    today_weekday        = long weekday name in {{$timezone}}
                            (run: TZ='{{$timezone}}' date '+%A')
    today_month_name     = long month name in {{$timezone}}
                            (run: TZ='{{$timezone}}' date '+%B')
    ...
    ```

    Plus the verbatim instruction: `do NOT use any example value`. Plus a fallback: "If you cannot run Bash in your environment, use any other tool that returns the actual current wall-clock date in {{$timezone}} — but DO NOT fabricate or guess."

## 3. Cost considerations

Negligible. Both knobs are static text additions to the wrapper body (~600-800 additional chars in each composed wrapper). No new MCP calls, no new helpers, no new sub-skills. The cron LLM reads slightly more text per fire; that's it.

## 4. Risk analysis

### 4.1 What could go wrong

- **A subscriber doesn't re-sync after deploy.** Their cron LLM keeps reading the v0.97.1 wrapper body and the bug persists. Mitigation: result doc + handoff explicitly require `/cowork sync-scheduled-jobs` re-run per vault.
- **The cron LLM ignores the anti-delegation directive.** Possible. But the directive is at the TOP of the wrapper — the first thing the LLM reads. If it still delegates, that's a deeper model-behavior issue.
- **The inline contract is verbose enough that the LLM "summarizes and delegates" anyway.** The anti-delegation directive explicitly addresses this: "If the wrapper feels long, that is intentional; follow it step-by-step rather than delegating."

### 4.2 What CAN'T go wrong

- The orchestrator-instructions files cached on disk still get auto-installed via dogfood + `sauce update`. The wrapper compose is fully deterministic — same inputs produce byte-identical wrappers.

## 5. Out-of-scope (parked)

- Full retirement of `write-run-note-<cadence>` SKILL.md files — kept as legacy/manual-invocation paths. The orchestrator-instructions just stop DELEGATING to them.
- Removing `cowork-reconciler` pure-Node mechanism — still queued for v0.98.0+.
- Per-skill SemVer + per-skill versioning CI — still queued.

## 6. Action required post-deploy

User runs `/cowork sync-scheduled-jobs` from claude.ai's Cowork UI per vault. Rail A's sync orchestrator pushes the new wrapper bodies (anti-delegation directive + inline contract + new PRELUDE) into the live scheduled tasks via `update_scheduled_task` MCP. Schedule preservation invariant holds: cron fields are never touched on update.

Both consumer vaults (headspace + accuris) need this — headspace was structurally GREEN this morning but it still benefits from the anti-delegation directive (one delegation-prone fire on the right day would have produced the same accuris-shaped breakage).
