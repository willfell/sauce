## Outcome summary

v0.78.1 is a SKILL.md prose-only patch that closes two v0.78.0 bugs
exposed by the accuris vault's 2026-05-28 morning-briefing autonomous
run. The run fell back to legacy mode citing "helper not materialized
in vault" and produced a GitHub PR section with no inline links — two
distinct contract gaps in v0.78.0's SKILL.md prose that v0.78.1
inverts and tightens. No new helpers, no manifest schema change, no
file-count change. Helpers added in v0.78.0 remain in the workshop for
harness use only (the agent-side algorithm in the inverted-contract
SKILL.md is the consumer-facing primary).

Fix (A) inverts the primary/secondary contract in
`read-user-preferences/SKILL.md` and the 5 orchestrator step 3c blocks.
v0.78.0 told the agent to "delegate to the helper at
`.local/blueprints/cowork/helpers/<name>-helper.js`" — but that path
never exists in consumer vaults (the v0.78.0 helpers live only in the
workshop dev repo under `platform/blueprints/cowork/helpers/` for
harness use). v0.78.1 promotes the agent-side algorithm to primary
documented behavior; helper-mention moves to a new `## Harness testing`
section that explicitly notes the helper is NOT materialized in
consumer vaults. Fix (B) adds a `## Source URL requirements` section to
`gather-from-served-by/SKILL.md` with MUST/SHOULD per-kind discipline
(github + ado + email = MUST; calendar + chat + finance = SHOULD;
custom = SHOULD) plus per-kind URL-shape examples and a fallback
`_did not expose URL fields_` note pattern for genuinely-no-URL runs.

Legacy fallback path is unchanged. +2 HC-V0781-* static prose-lint
test cases in `run-cowork-smoke.js` gate both fixes: A1 enforces the
"agent-side algorithm primary + `## Harness testing` section present"
contract on `read-user-preferences/SKILL.md`; B1 enforces the
`## Source URL requirements` section and the MUST/SHOULD per-kind
discipline on `gather-from-served-by/SKILL.md`.

## Behavioral changes

**SKILL.md primary/secondary contract inverted (Fix A).** v0.78.0's
`read-user-preferences/SKILL.md` and the 5 orchestrator step 3c blocks
opened with a directive shaped like "delegate to the helper at
`.local/blueprints/cowork/helpers/<name>-helper.js`". That path is a
workshop-only artifact — `platform/blueprints/cowork/helpers/*-helper.js`
files are NOT shipped to consumer vaults by the installer (they exist
only in the dev repo for the unit-testable harness path). The accuris
vault agent treated the missing helper as a hard signal to fall back
to legacy mode, bypassing all v0.78.0 prefs-driven behavior. v0.78.1
inverts the contract:

- **Primary documented behavior:** the agent-side algorithm (read +
  parse + extract prefs / dispatch served_by lookup / emit warning
  callouts). The SKILL.md walks the agent through the steps directly,
  using only the consumer-vault file shapes that always exist.
- **Secondary (harness-only) note:** a new `## Harness testing`
  section that explains the equivalent helper exists in the workshop
  dev repo for static-test purposes and explicitly states it is NOT
  materialized in consumer vaults — so the agent should never look for
  it. This closes the previously-ambiguous prose without removing the
  workshop helpers (the harness path keeps using them).

Files touched in S2 (SKILL.md prose only):

- `platform/blueprints/cowork/skills/skills/read-user-preferences/SKILL.md`
- `platform/blueprints/cowork/skills/orchestrators/morning-briefing/SKILL.md`
- `platform/blueprints/cowork/skills/orchestrators/midday-tripwire/SKILL.md`
- `platform/blueprints/cowork/skills/orchestrators/eod-review/SKILL.md`
- `platform/blueprints/cowork/skills/orchestrators/weekly-review/SKILL.md`
- `platform/blueprints/cowork/skills/orchestrators/monthly-review/SKILL.md`

**Source URL contract added to `gather-from-served-by` (Fix B).**
v0.78.0's `gather-from-served-by/SKILL.md` output contract had no URL
requirement, so the accuris run's GitHub PR section came back as
link-less prose. v0.78.1 adds a `## Source URL requirements` section
with MUST/SHOULD per-kind discipline:

- **MUST include source URL per item** (hard failure if missing):
  `github` (PR + issue URLs), `ado` (work item + PR URLs), `email`
  (mailto: or webmail message URL).
- **SHOULD include source URL per item** (soft, fallback note allowed):
  `calendar` (event URL), `chat` (deep-link to message/thread),
  `finance` (transaction URL), `custom` (vendor-specific URL when one
  exists).
- **Per-kind URL-shape examples** in the SKILL.md prose, so the agent
  knows the canonical URL pattern for each known kind.
- **Fallback note pattern** (`_did not expose URL fields_`) for
  genuinely-no-URL runs — keeps the SHOULD-tier honest without
  forcing the agent to fabricate URLs.

Files touched in S2 (SKILL.md prose only):

- `platform/blueprints/cowork/skills/skills/gather-from-served-by/SKILL.md`

**No code-path changes.** Helpers (workshop dev repo only),
orchestrator step ordering, dispatch logic, legacy fallback, and
voice-contract composition are all bit-for-bit identical to v0.78.0.
