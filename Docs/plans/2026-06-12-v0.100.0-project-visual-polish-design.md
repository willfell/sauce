# v0.100.0 — project visual polish

## TL;DR

The project blueprint's Docs hub renders doc-notes as an auto-fit card grid;
past a handful of docs the grid stops being scannable. The project nav row
uses a hand-rolled muted button style that hugs the left edge and sits
cramped against its divider. Two helper-level changes, zero new mechanisms:

1. **Docs hub → list rows.** `ProjectDocsCards` switches its `BeaconCards`
   call to `layout: "row"` — single-column, full-width rows, most recently
   edited first, with `created <MMM D> · edited <relative>` metadata on the
   right. Fixes a latent bug while there: the helper sorts/subtitles on
   `p.created`, but doc-notes ship `created_at` frontmatter, so the subtitle
   rendered empty and the sort key was dead (ordering silently fell through
   to the BeaconCards default).
2. **Nav buttons → accent + full width.** `ProjectNavButtons` drops its
   hand-rolled muted-button loop and renders each nav button through
   `customJS.AccentButton.render(..., { flex: true })` — identical styling
   to the New Doc / New Note buttons by construction, stretched evenly
   across the note width. The divider above the "PROJECT" label gets more
   bottom margin so the section breathes.

Both files live in `platform/blueprints/project/helpers/`. Blueprint MINOR;
workshop MINOR as its own cycle.

## Decisions (locked at brainstorm, 2026-06-12)

| Question | Decision |
| --- | --- |
| Row metadata | Edited + created, right-aligned: `created May 28 · edited 2d ago` |
| Sort order | Last edited first (file mtime desc; covers just-created docs) |
| Button sizing | Stretch evenly — each button grows equally to span the full row |
| Restyle scope | ProjectNavButtons ONLY. SpaceNavButtons + finance/trip nav rows stay muted (nav-vs-action color distinction intentionally broken only where the user asked) |

## Section 1 — Docs hub list (`project-docs-cards.js`)

- Query unchanged: doc-note siblings of the hub folder
  (`dv.pages("<docsFolder>").where(p => p.type === "doc-note")`).
- Drop the Dataview-side `.sort((p) => p.created, "desc")` — wrong key
  (doc-notes carry `created_at`) and dead anyway (BeaconCards re-sorts).
- `BeaconCards` options change:
  - `layout: "row"` (columns defaults to 1 → single-column rows).
  - Ordering: BeaconCards' default sort (`file.mtime.ts` desc) — explicitly
    relied upon; no `sort` option passed.
  - `meta` callback replaces the under-title `subtitle`:
    `created <MMM D> · edited <moment().fromNow()>`. Created reads
    `created_at` frontmatter, falling back to `p.file.ctime` for
    pre-canonical notes. Plan-time note: Dataview parses ISO frontmatter
    dates into DateTime objects — the formatter must handle both string and
    DateTime shapes robustly.
  - `icon`: the small accent file glyph, matching the task-note tiles in
    task hubs (stroke `var(--interactive-accent)`).
- Empty state ("No docs yet · Click + New Doc…") unchanged.
- Mobile: row layout stacks metadata under the title automatically —
  built into `BeaconCards._renderRowCard`; no extra work.

## Section 2 — Nav buttons (`project-nav-buttons.js`)

- Spacing: the top divider's margin grows `8px 0 6px 0` → `8px 0 14px 0`
  so the "PROJECT" section label separates from the rule above it.
- The hand-rolled `btnStyle` string + per-button hover handlers are
  DELETED. Each entry in `buttons[]` renders via
  `customJS.AccentButton.render(container, { label, icon, onClick, flex: true })`
  with `onClick: () => app.workspace.openLinkText(btn.path, "")`.
  - Styling matches New Doc by construction (same mechanism; accent
    outline, accent fill on hover).
  - `flex: true` appends `flex: 1; min-width: 0` — buttons stretch evenly
    to span the row. Container keeps `display: flex; flex-wrap: wrap;
    gap: 6px`; if the row wraps on narrow panes each line still fills its
    width (same behavior as the existing task action row).
  - Button labels need a nowrap span equivalent preserved — verify at plan
    time whether AccentButton's plain `<span>` wraps long labels
    (e.g. `Task: doc-db-testing`) acceptably.
  - Icons already use `stroke="currentColor"` → tint accent for free.
- UNTOUCHED: context detection, workstream widget + Change button, the
  New Note / Open Board / Create Board action row (already AccentButton),
  task-note tiles, the `pnb-root` re-render dedupe wrapper.
