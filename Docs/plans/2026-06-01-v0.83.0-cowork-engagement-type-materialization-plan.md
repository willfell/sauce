# v0.83.0 cowork-engagement-type-materialization — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make cowork's three engagement-type JSON manifests reachable at runtime on consumer vaults by materializing them via `files[]`, and update all 7 orchestrators that consume them to read the canonical materialized path.

**Architecture:** Add 3 entries to cowork's `files[]` so `engagement-types/{personal,w2-fte,consulting}.json` materialize to `spice/cowork/context/engagement-types/<type>.json`. Update 5 atomic-note orchestrators (midday-tripwire/morning-briefing/eod-review/weekly-review/monthly-review) to read the canonical path. Simplify bootstrap-vault + onboard-scheduled-jobs to read materialized path directly (drop workshop-path resolution + override-merge). Codify engagement-type JSONs as STOCK in cowork-customization-contract.md. Bump workshop `0.82.1 → 0.83.0` (MINOR) and cowork `0.21.1 → 0.22.0` (MINOR).

**Tech Stack:** Node.js installer (filesystem-only), JSON blueprint manifests, claude_surface[]-managed SKILL.md prose, run-cowork-smoke.js static-validator harness, npm run release:preflight gated on scripts/check-version-sync.js.

**Design reference:** `Docs/plans/2026-06-01-v0.83.0-cowork-engagement-type-materialization-design.md` (commit `f50a8a1`).

**Cycle conventions (baked in):**

- Direct-push to `origin/main`; one commit per stage; conventional-commits format; NO `Co-Authored-By` trailer.
- Explicit `git add <paths>` per stage; never `git add -A`.
- Each stage runs `npm run release:preflight`; ALL GREEN required to advance.
- Dogfood install: `node platform/install.js --vault . --auto-approve`.
- After ANY SKILL.md / manifest change that touches a `claude_surface[]`-managed surface, re-materialize via dogfood install + stage the regenerated `ranch/` + `.claude/` files in the same stage commit.
- USER APPROVAL required before pushing any annotated tag.
