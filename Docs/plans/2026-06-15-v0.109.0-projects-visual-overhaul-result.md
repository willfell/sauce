## Lessons

1. **Cycle-number collision recovery is non-trivial.** When the handoff author and the executor live in different sessions, the explicit version number in the handoff can be reused by a parallel cycle before the executor reads it. Mitigation: at session-start, ALWAYS check `git log` for in-flight commits matching the target version BEFORE accepting the handoff verbatim. Captured in the worktree's result/handoff for future agents.
2. **Stale legacy version-pin assertions cluster.** Eleven `assertEqual(..., "0.107.0", ...)` assertions clustered in run-helper-cases.js had to be bulk-bumped. Pattern: every workshop bump probably needs a `"<old>" → "<new>"` `replace_all` sweep across run-helper-cases.js + run-bootstrap.js. Add to release.workflow gate checklist.
3. **Self-subscription pin is a deploy gate, not advisory.** Workshop dogfood install REFUSED to materialize the new helpers until both `ranch/platform-subscription.json` AND `platform/manifest.json` (workshop-level catalogue) were both lockstep-bumped alongside the blueprint's own manifest. Three pins minimum per blueprint bump: blueprint manifest version + workshop catalogue entry version + self-subscription pin version. Document explicitly in `build-test-verify.md` § version-pin sweep.
4. **Legacy test fixtures pin OLD contracts.** S5 + S6 each surfaced 4+ legacy HC tests pinning the OLD ProjectMeetingsPanel + Template behavior (5-cap, expand toggle, info callout, `## Status` H2, `## Mentions` ordering). Each needed inline supersession — preserving the new contract via assertion negation rather than deletion. Cost: ~3 minutes per test, total ~15 minutes. Standard intra-cycle hygiene.
5. **Worktree relocation works late in a cycle.** Even after 10 stages committed on `main`, moving to a worktree is a safe `git branch` + `git reset --hard` + `git worktree add` sequence — provided the in-flight changes from a parallel session are NOT carried on the same uncommitted-state tracks. (This cycle had no live working-tree state — the stash attempt at handoff returned "No local changes" because S10's dogfood install had already committed everything finance-adjacent into the cycle's S10 chore commit. Future cycles in this shape should verify nothing escapes into the relocated history.)
