## Spec interpretations and divergences

Five divergences, all surfaced by a harness and each pinned with a test:

1. **Entry rule.** The design implied "a node with no incoming edge starts the run"; the minimal graph's retry edge back to `implement` broke that, and the first fix ("no incoming *unbounded* edge") made repair steps reachable only through bounded edges into accidental entries in the delivery graph. Final rule: the first declared node, plus every node nothing points at.
2. **YAML subset** gained single-line flow sequences (`fake: [fail, pass]`), and `run: true` is coerced to the string command rather than refused as a boolean.
3. **Variable substitution** is bounded-recursive so a graph `vars:` default can reference another var (the delivery graph builds its commands that way); a self-reference is refused after five passes.
4. **Run ids** get a `-2`, `-3` suffix when two runs mint in the same second; the harness produced the collision and the second run silently replayed the first's ledger.
5. **`follow` stops at a human node by default** (`--wait-human` keeps polling); the harness hung for two minutes polling a parked run before this was made the default rather than a CLI-side hook.

Two things the design listed as MVP moved: `gate: adequacy` is supported on `judge` nodes but the shipped graph calls `gate.js` through a `vars.adequacy_command` default instead, so the harness can substitute `true`; and `--install-launchd` shipped in this cycle (the design had it as follow-up) because the Director made the plist a condition of deleting the old sample.

## The review round (2026-09-22, post-CI)

A fresh adversarial reviewer was dispatched against the branch with a brief to refute, not approve. It returned **REFUTED** with six merge-blocking findings, each proved on a scratch copy rather than asserted. All six are fixed on this branch, and each fix carries a test that fails without it.

| # | Finding | Fix |
| --- | --- | --- |
| 1 | The coordinator's `advance` can return `action: 'parked'`; the graph had no edge for it, and because `isTerminal` compared status strings, the resulting `run.ended` left the run non-terminal with no checkbox. An unattended run would wedge forever holding the card lease and still exit 0. | `state.terminal` is now a fact the ledger records, so any `run.ended` is terminal whatever its outcome is named. The graph routes `on: parked` to a `parked-on-dependency` end node. DR-9e, DR-9f. |
| 2 | Six repair edges each carried `max: 1`, so refutations from different lenses bought up to six repairs. The Director's law is one repair, then supersede. | New `budget: <name>` on edges: edges sharing a budget share one counter, and every repair edge is on `budget: repair`. DG-7, DR-9c. |
| 3 | `fix-ci` and `refresh` re-entered through `pr`, which re-ran `gh pr create` on an existing PR, failed, and killed the run with the lease still held. The commonest real path (CI fails once) always died. | The `pr` command views before it creates. DG-9, DG-9b, DR-9d. |
| 4 | Command injection: card titles and agent-written review summaries were spliced unquoted into a `shell: true` spawn. A card title containing a command substitution executed, and the `--card` operand was silently corrupted while the run still reported done. | Substitution into `run:` now shell-quotes every value, with an explicit raw opt-out for command fragments. VR-7, VR-8, VR-9, DR-9g. |
| 5 | The lease-token rule was proved for one of four leased verbs; the harness stayed green with the token dropped from the other three. | DG-6b (static, all four verbs) and DR-9h (runtime, every mutating call carried the claim's token). |
| 6 | The action-coverage proof was circular: the expected action set was hand-written in the test, so an action nobody remembered was invisible. Four non-blocking findings were fixed too. The sweep failed open toward deletion, and now keeps a worktree on a dirty tree, a detached HEAD, or a base it cannot measure against (IS-6, IS-7). `ensureAlwaysOnMechanisms` left a stale pin that `resolveDependencies` then skipped forever, so an always-on mechanism silently stopped installing; it now repairs the pin (AO-3b). `throwsWith` ignored its own regex, so two parser tests asserted almost nothing. And `/mayo:run` documented a `policy.engine` binding knob that no code reads; the claim is gone.

Writing the fixes surfaced one more defect of my own making: the shared budget was written by the reducer under the raw edge key and read by the matcher under the budget key, so it never exhausted and the delivery graph looped forever. The ledger's `edge.fired` event now carries its budget and the reducer keys on it.

## NEW lessons

- **Two review rounds found defects the first could not.** Round one found six; round two found three more, two of them created by round one’s fixes. A repair is a change like any other and deserves the same adversary.
- **A quoting fix that loops is not a quoting fix.** Re-scanning your own output re-interprets the very data you just neutralized; the boundary between template and leaf has to be structural, not a pass count.
- **An adversarial reviewer earns its cost on a first release.** Six blocking defects survived a green 183-step preflight, because the tests were written by the same mind as the code. The two that mattered most were failures of the proof, not the implementation.
- **A shared counter read under one key and written under another never trips.** My own budget fix looped forever until the reducer and the matcher agreed; the ledger event now carries the budget so a replay cannot disagree.
- **Quote at the boundary, not at the call site.** Shell-quoting every substituted value broke the vars holding whole commands, which is the signal that operands and command fragments are different things and need different syntax.
- **A harness that hangs is a design finding, not a flake.** `follow` polling a parked run forever was a wrong default, not a slow test; the fix was in the engine, and the CLI hook that had masked it was deleted.
- **Same-second run ids collide in tests long before they collide in life.** Any id built from a timestamp needs a collision suffix on day one; the harness found it within minutes.
- **A heredoc with `${` inside a JS template literal will eat your file.** One test edit lost its tail to shell-free template interpolation and cost three amend cycles; write test edits with the Edit tool or a quoted-string script, never by string-replacing into a template literal.
- **`git add scripts/…` is refused on macOS** (`/Scripts/` ignore + case-insensitive FS); use `git commit -a` or `git add -f`.
