`_did not expose URL fields_` note pattern for genuinely-no-URL runs.

HC-V0781-* static SKILL.md prose-lint cases in `run-cowork-smoke.js`.
Workshop 0.78.0 → 0.78.1; cowork blueprint stays at 0.17.0 (prose-only
patch). Forcing function: the accuris 2026-05-28 morning-briefing
autonomously fell back to legacy mode citing "helper not materialized
