**Goal:** Replace v0.76.0's namespace-regex MCP detection with tool-pattern matching (capability-subset model: an MCP namespace can satisfy multiple kinds via tool-name set membership). Add a fully-adaptive unknown-MCP handling loop that surfaces unmapped MCPs to the user for classification (known-override OR custom kind with free-text `what_matters`). Renames `gmail`→`email` and `imessage`→`chat` with in-place migration of v0.76.0-shaped user-preferences.md.

**Architecture:** Four workstreams in one minor cycle. (B) `mcp-skill-map.json` v1→v2 schema change + new `detectCapabilities(availableTools, mcpSkillMap)` helper export — set-membership matching across the agent's tool list, returns `{ detected: [{kind, served_by, matched_tools}], unmapped_namespaces: [] }`. (C) new `## Unknown-MCP loop` section in `cowork:context-builder` SKILL.md + `unknown_namespace_classifications` dry-run-answer shape + `custom_kind: true` + `what_matters` block in user-preferences.md schema. (D) `migrateV1ToV2(existingPrefs, mcpSkillMap)` helper that applies `rename_from_v1` mappings on read; idempotent. (F) static schema validation case for v2 shape.

**Tech Stack:** Node 20+ (workshop CLI + helper); Claude Code skill bodies (markdown SKILL.md); workshop test harnesses (`platform/test/run-*.js`).

Open `platform/blueprints/cowork/helpers/context-builder-dry-run.js`. Find the existing `composeYaml` function (line ~68) and the `run()` function (line ~102). Insert the following NEW function BEFORE `run()`:

```javascript
// v0.77.0 Workstream B: tool-pattern detection. Capability-subset model —
// an MCP namespace satisfies a `kind` when its tool set contains ALL of the
// kind's `required_tools`, OR fully satisfies any branch of `tool_alternatives`.
// A single namespace can satisfy multiple kinds (Outlook UUID = calendar + email + chat).
//
// availableTools: array of "mcp__<ns>__<tool>" strings (the agent's tool list)
// mcpSkillMap:    parsed mcp-skill-map.json (v2.0.0 shape)
//
// returns: { detected: [{kind, served_by, matched_tools, gather_skill}], unmapped_namespaces: [...] }
function detectCapabilities(availableTools, mcpSkillMap) {
    // Group tools by namespace
    const toolsByNamespace = {};
    for (const fullName of (availableTools || [])) {
        const m = fullName.match(/^mcp__([^_]+(?:_[^_]+)*?)__(.+)$/);
        // Greedy namespace match: "mcp__<ns>__<tool>" where ns may contain underscores
        // (e.g. Google_Calendar). We use a non-greedy-then-greedy split: take everything
        // after mcp__ as ns_tool, then split on the LAST __ pair.
        if (!m) continue;
        // Re-split: prefer the right-most "__" as the namespace/tool boundary.
        const inner = fullName.substring("mcp__".length);
        const idx = inner.lastIndexOf("__");
        if (idx < 0) continue;
        const ns = inner.substring(0, idx);
        const tool = inner.substring(idx + 2);
        if (!ns || !tool) continue;
        if (!toolsByNamespace[ns]) toolsByNamespace[ns] = new Set();
        toolsByNamespace[ns].add(tool);
    }

    const detected = [];
    const bound = new Set(); // ns values that satisfied at least one kind

    for (const entry of (mcpSkillMap.kinds || [])) {
        const required = entry.required_tools || [];
        const alts = entry.tool_alternatives || [];
        for (const ns of Object.keys(toolsByNamespace)) {
            const tools = toolsByNamespace[ns];
            const allReq = required.length > 0 && required.every(t => tools.has(t));
            const anyAlt = alts.length > 0 && alts.some(alt =>
                Array.isArray(alt) && alt.length > 0 && alt.every(t => tools.has(t))
            );
            // A kind with `tool_alternatives` requires both (a) required_tools fully present
            // AND (b) at least one alt branch fully present. A kind without tool_alternatives
            // is satisfied by required_tools alone.
            const matches = alts.length > 0
                ? (allReq && anyAlt)
                : allReq;
            if (matches) {
                // Compose matched_tools = union of required_tools + matched-alt + optional_tools present
                const matchedAlts = alts.find(a => a.every(t => tools.has(t))) || [];
                const optionals = (entry.optional_tools || []).filter(t => tools.has(t));
                const matched_tools = Array.from(new Set([...required, ...matchedAlts, ...optionals]));
                detected.push({
                    kind: entry.kind,
                    served_by: ns,
                    matched_tools,
                    gather_skill: entry.gather_skill,
                });
                bound.add(ns);
            }
        }
    }

    const unmapped_namespaces = Object.keys(toolsByNamespace).filter(ns => !bound.has(ns));

    return { detected, unmapped_namespaces };
}
```

```javascript
// v0.77.0 Workstream D: migrate v0.76.0-shaped user-preferences.md to v0.77.0
// shape by renaming kind keys per the rename_from_v1 hints in the v2 map.
// Idempotent: if the prefs are already v2-shaped, returns them unchanged.
//
// existingPrefs: parsed user-preferences.md frontmatter object (may be null)
// mcpSkillMap:   parsed mcp-skill-map.json (v2.0.0 shape)
//
// returns: new prefs object with keys renamed; safe to call repeatedly
function migrateV1ToV2(existingPrefs, mcpSkillMap) {
    if (!existingPrefs) return existingPrefs;
    const renameMap = {}; // old → new
    for (const entry of (mcpSkillMap.kinds || [])) {
        if (entry.rename_from_v1 && entry.kind && entry.rename_from_v1 !== entry.kind) {
            renameMap[entry.rename_from_v1] = entry.kind;
        }
    }
    if (Object.keys(renameMap).length === 0) return existingPrefs;

    // Deep copy to avoid mutating caller's object
    const next = JSON.parse(JSON.stringify(existingPrefs));

    // Rename mcps.<old> → mcps.<new>
    if (next.mcps && typeof next.mcps === "object") {
        for (const oldKey of Object.keys(renameMap)) {
            const newKey = renameMap[oldKey];
            if (next.mcps[oldKey] !== undefined && next.mcps[newKey] === undefined) {
                next.mcps[newKey] = next.mcps[oldKey];
                delete next.mcps[oldKey];
            }
        }
    }

    // Rename priorities[] entries
    if (Array.isArray(next.priorities)) {
        next.priorities = next.priorities.map(p => renameMap[p] || p);
    }

    return next;
}
```

```javascript
function parseYamlIsh(yaml) {
    const out = {};
    const lines = yaml.split("\n");
    let i = 0;
    while (i < lines.length) {
        const line = lines[i];
        if (!line.trim() || line.trim().startsWith("#")) { i++; continue; }
        const flat = line.match(/^([a-z_]+):\s*(.*)$/);
        if (!flat) { i++; continue; }
        const [, key, valRaw] = flat;
        const val = valRaw.trim();
        if (val === "|") {
            // YAML literal block scalar — gather subsequent indented lines as the value
            i++;
            const blockLines = [];
            // Detect the indent of the first child line
            let blockIndent = null;
            while (i < lines.length) {
                const ln = lines[i];
                if (ln.trim() === "") { blockLines.push(""); i++; continue; }
                const indentMatch = ln.match(/^(\s+)/);
                const indent = indentMatch ? indentMatch[1].length : 0;
                if (blockIndent === null) blockIndent = indent;
                if (indent < blockIndent) break;
                blockLines.push(ln.substring(blockIndent));
                i++;
            }
            // Trim trailing blank line(s) commonly emitted by YAML serializers
            while (blockLines.length && blockLines[blockLines.length - 1] === "") blockLines.pop();
            out[key] = blockLines.join("\n");
            continue;
        }
        if (val === "") {
            const nextLines = [];
            i++;
            while (i < lines.length && (lines[i].startsWith("  ") || lines[i].startsWith("\t") || lines[i].trim() === "")) {
                nextLines.push(lines[i]);
                i++;
            }
            if (nextLines.every(l => !l.trim() || /^\s+- /.test(l))) {
                out[key] = nextLines.filter(l => l.trim()).map(l => l.replace(/^\s+-\s*/, "").trim());
            } else {
                out[key] = parseYamlIsh(nextLines.map(l => l.replace(/^  /, "")).join("\n"));
            }
            continue;
        }
        if (val.startsWith("[") && val.endsWith("]")) {
            out[key] = val.slice(1, -1).split(",").map(s => s.trim().replace(/^["']|["']$/g, "")).filter(Boolean);
        } else if (val === "true") out[key] = true;
        else if (val === "false") out[key] = false;
        else if (val === "null") out[key] = null;
        else if (/^-?\d+$/.test(val)) out[key] = parseInt(val, 10);
        else out[key] = val.replace(/^["']|["']$/g, "");
        i++;
    }
    return out;
}
```

Include these LESSONS LEARNED at minimum (expand each into a paragraph):

1. **Capability-subset model.** v0.76.0 assumed each MCP namespace was ONE kind. Real-world enterprise gateways (Outlook M365, internal corporate MCPs) bundle multiple capabilities under one namespace. The set-membership matching model lets the same namespace satisfy `calendar` AND `email` AND `chat` simultaneously, with `served_by` recording which namespace each capability came from. Cleaner than per-MCP classification.

2. **Tool-pattern detection vs namespace regex.** v0.76.0's regex matched literal vendor names (`Google_Calendar`, `Gmail`, etc.). The accuris machine's UUID namespace defeated this entirely. Pattern detection on tool NAMES (`list_events`+`create_event`) is robust against any namespace format — including future MCPs we haven't seen.

3. **YAML literal blocks needed for free-text fields.** v0.76.0's compose handled flat scalars and arrays. The Workstream C `what_matters` field is multi-line free text — required adding the `key: |` YAML syntax to both `composeYaml` and `parseYamlIsh` (the round-trip needed to be byte-stable for HC-V0770-C2's Skip re-run preservation).
