## Lessons

1. **One large S1 subagent dispatch worked.** Bundling Tasks 2-10 (contract + 12 fixtures + helper + 4 HC groups + manifest + version bumps) into a single subagent dispatch produced a coherent S1 close in one shot. The subagent self-verified byte-identical fixture round-trip + all 4 HC groups pass + dogfood install clean. Compare v0.92.0 where I broke S1 into 3 subagent dispatches (fixtures / helper / HC wiring) — the v0.93.0 single-dispatch approach was more efficient at the cost of less per-stage review granularity.

2. **Fixture-as-spec discipline pays off.** All 8 byte-identical fixtures + 4 validator-failure fixtures were authored UP FRONT in S1 BEFORE the helper code. The helper had to satisfy them. This is fixture-driven TDD in action; the subagent never "drifted" the fixtures to match a buggy implementation. case-accuris-shape (load-bearing, derived from accuris-sauce/Planning/cowork-scheduled-job-wrappers-v0.91.3.md) anchors the realism check; case-novel-mcp-shape with the contrived `slack` kind enforces the B4 dynamic-design guarantee.

3. **The dynamic-design commitment (B4) is testable.** case-novel-mcp-shape proves the helper handles previously-unseen MCP kinds without any contract.json changes. This is the load-bearing test for the architectural promise: "fully dynamic; every vault has its own connections; nothing is default; flexible for any user's connection needs." Without this fixture, the commitment would be aspirational; with it, it's testable.

4. **4-mode substitution-token validator is per landmine #20.** The validator catches typos in `{{$varname}}` tokens (undeclared), unknown `{{shared.<key>}}` references, invalid-format `{{anything}}` patterns (defends against installer-style `{{template_variables}}` accidentally landing in contract.json), and post-render leaks (substitution missed). Each mode has its own validator-failure fixture. Mode 4 (post-render leak) is the hardest to trigger — the subagent solved it by routing a literal `{{leftover_token}}` through `{{$voice_notes_excerpt}}` substitution (so it passes Mode 3 format check on the OUTSIDE but leaks `{{` on the INSIDE).

5. **Consumer install deferred to post-Homebrew-release.** Same pattern as v0.92.0: consumer vaults cache `installed.workshop_path` pointing at the brew Cellar version. Direct `node /Users/willfellhoelter/projects/repos/sauce/platform/install.js --vault <consumer>` doesn't bridge the dev workspace → consumer gap until `brew upgrade sauce` ships v0.93.0. Pin bumps are committed; live materialization is post-release verification. This is the existing workshop convention (see v0.85.1 cycle-history entry).

6. **MICROSCOPES clause is per-cadence.** midday-tripwire's `includes_microscopes: false` means its wrapper_template omits the MICROSCOPES non-negotiable clause. Other 4 cadences (morning-briefing, eod-review, weekly-review, monthly-review) include it. This is a real per-cadence difference encoded in contract.json (not just title-text substitution). Tests for this via the case-accuris-shape fixture's byte-identical output.
