### Steps inside `reconcile-cowork.md`

1. Pre-flight (Obsidian MCP + vault-config.md + date resolution including `yesterday_date`/`yesterday_dirpath`).
2. List yesterday's atomic notes (`spice/cowork/daily/<yesterday_dirpath>/`).
3. Backfill missing `.cowork.json` sidecars from `.md` prose.
4. Parse rating callouts (sentinel `<!-- cowork:rating-block schema=1.0.0 cadence=<X> day=<Y> -->`).
5. Update `learned_weights` in `user-preferences.md` with update formula: `w_raw = w_old * 0.98 + 0.15 * (tick_count - 0.5 * skip_count) / (tick_count + skip_count + 5)`; clamp `[0.10, 3.00]`; banker's rounding; warmup graduation rules.
6. Write `.bak` + updated user-preferences.md (preserves all other top-level frontmatter keys).
7. Heartbeat check (walk 30-day sidecar window; freshness windows: 36h for morning/midday/eod/capture-tick, 192h for weekly/synthesize-week/lens_shift, 840h for monthly).
8. Emit `> [!warning]+ Cron heartbeat anomaly` callout to memory.md if any cadence missed.
9. Append reconciler-log entry capped at 30 entries.

## Open observations

The reconciler being doable in pure MCP (no Node helper at fire time) validates the v0.97.0 Rail O direction — orchestrator-instructions can fully describe the work for the LLM to execute via tools. The local-Node Rail R mechanism from v0.97.0 was over-built; the same effect achievable via a cadence + LLM was always possible. v0.97.1 closes that loop.

Performance estimate: ~50-160 MCP calls per fire per engagement, bounded by 30-day sidecar walk. Acceptable for nightly automation.
