## What shipped (one-paragraph summary)

v0.75.1 closes all v0.75.0 deploy carry-forwards and first-fire correctness issues. `sauce update --bump-pins` now auto-detects the workshop path when `ranch/platform-installed.json` has `workshop_path: null` (which it does on every pre-v0.75.1 consumer vault) via a four-source precedence helper — the two manual jq-patches from the v0.75.0 deploy recipe are no longer needed. `sauce update` against non-git consumer vaults is now end-to-end: the legacy git-fetch + reset path (dead since brew distribution) has been removed; the command delegates directly to the installer. sc-bridge `--quiet` now actually suppresses non-fatal stderr. `installed.workshop_version` is refreshed on every install. 93 emoji characters were stripped from 15 engagement-template prompts (fail-closed audit gate HC-V0751-A1 prevents reintroduction). Morning-briefing's semantic-warning misfire is fixed and warning text is aligned with the sub-skill's canonical contract. 11 new harness cases. Per-vault deploy of v0.75.1 is `sauce update --bump-pins` — no extras.

Cowork 0.14.0 → 0.14.1. smart-connections-bridge 0.1.0 → 0.1.1. Engagement-types 0.3.0 → 0.3.1. Workshop 0.75.0 → 0.75.1.
