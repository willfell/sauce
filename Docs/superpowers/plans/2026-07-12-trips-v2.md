# Trips Blueprint v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lift the trips blueprint to full platform parity — chrome-bar-hosted actions, real task-note parity with projects, multi-leg flights with typed date/time forms, links on the atlas, human-readable dashboard, upcoming-trips on the daily/home, and proper board-card chrome.

**Architecture:** Extend the shared `task-entity` mechanism with generic `trip`/`trip_slug` fields + a `TaskTripList`; move every section "Add" action onto `TripsChromeBar` (primary right of compass / ⋯ overflow) keyed on `section_kind`; give `TripEntryList` typed form fields (date/time/select/link) and flight direction-grouping; drop the Links section in favor of atlas-hosted links; format dashboard dates; add a `selectUpcomingTrips` selector to `SpaceDailyDashboard`; and register a `trip-board-card` breadcrumb + chrome.

**Tech Stack:** customJS helper classes (single bare `class X {}` expression, NO trailing statements), Dataview render blocks, Obsidian `app.fileManager.processFrontMatter` + `app.vault.create`, native `<input type=date|time|url>` with the iOS-safe `dateCss` pattern, Node behavioral harness (`platform/test/run-*.js`), `platform/install.js` heals, `platform/schemas-index.json`.

**Reference files (read before coding the relevant task):**
- Task model: `platform/mechanisms/task-entity/task-entity.js` (`composeNote` ~L306-345 schema; `parseNote` ~L346-370), `task-dialog.js` (`open`/`_create` ~L431/L1250; `Due` date field + `dateCss` ~L710-737), `task-project-list.js` (`render`/`_matches` ~L40-146).
- Chrome bar: `platform/mechanisms/chrome-bar/chrome-bar.js` (`makeAdapter`/`render`; primary ~L297, overflow ~L308 via `MenuPopover`), `platform/blueprints/project/helpers/project-chrome-bar.js` (`_surfaceSpec` ~L272-305, `_dispatch` ~L469-540 — precedent for per-section Add).
- Trips: `platform/blueprints/trips/helpers/trips-chrome-bar.js`, `trip-entry-list.js`, `trip-section-kinds.js`, `trip-dashboard.js`.
- Links precedent: `platform/blueprints/project/helpers/project-links-manager.js`/`project-links-panel.js`.
- SpaceHome/daily: `platform/blueprints/home/helpers/space-home.js`, `platform/blueprints/daily/helpers/space-daily-dashboard.js` (`selectTasks` ~L136, `selectMeetings` ~L188).
- Board cards: `platform/blueprints/project/templates/Task Card.md` + project manifest `breadcrumb.types["task-board-card"]`.

**customJS invariant:** every helper file is a single bare `class X { ... }` expression, NO trailing statements. Static methods for pure ops; instance `render`/handlers.

**Convention:** commit after each green task. Do NOT bump manifest `version`/`package.json`/pins/tags — the release pipeline owns that.
