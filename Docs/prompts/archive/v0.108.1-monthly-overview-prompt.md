## v0.108.1 ask — `MonthlyOverview` band

The user wants, for any given month (e.g. July 2026):
- Total income (sum of all paychecks dated that month)
- Total spending (current Budget actuals for that month)
- Total debt paydown (sum of debt-linked paycheck expenses with `paid: true`)
- Debt balance delta MoM (uses `balance_history[]` on each debt entity)
- Headline math: **income − spending − debt paydown = net cashflow** (red if negative; green if positive)

This is the cohesion piece the v0.108.0 brief originally listed but we deferred. Debt schema already supports the aggregation.

## Location (decided in brainstorm)

`MonthlyOverview` band extends `Budget-<YYYY-MM>.md` — renders ABOVE the existing `BudgetSummary` band at the top of every monthly budget note. Reasons (locked at Q5 of brainstorm):
- one note per month is right
- a "budget" and a "monthly view" are the same conceptual thing through different lenses
- zero new sub-area, zero migration, zero EntityCreate plumbing
- `[[Budget-2026-07]]` is already the wikilink users type

## Plan shape

Single new helper `MonthlyOverview` at `platform/blueprints/finance/helpers/monthly-overview.js`. Three-band:

- Band 1 — headline: Income · Spending · Debt paydown · **Net cashflow** (colored). Same color palette as BudgetSummary (#16a34a / #b45309 / #dc2626).
- Band 2 — debt summary mini-row: total debt balance + month-over-month delta (sums `balance_history[]` snapshots per debt for first-of-month and last-of-month if available; else just current).
- Band 3 — sources strip: list of paychecks counted, count of debt entities surveyed.

Reads data via `dv.pages('"spice/finance/paychecks"').where(p => p.type === "paycheck" && p.pay_period_start in month)`, `dv.pages('"spice/finance/debts"').where(p => p.type === "debt")`, and current budget's `categories[]`.

Installer migration: `applyFinanceBudgetMonthlyBandInjection` — append-only injects `MonthlyOverview` dataviewjs block above the `<!-- budget-summary-v0.5.2 -->` marker (similar posture to `applyFinanceBudgetBodyMigration`). Marker comment `<!-- monthly-overview-v0.6.1 -->`.
