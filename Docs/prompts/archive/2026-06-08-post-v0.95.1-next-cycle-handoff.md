## 7-day quality observability window (post-v0.95.1 deploy)

Per result doc § Quality observability window: grade 7-14 days of consumer-vault atomic notes against:

- **Knob 1 (anti_echo):** opt in on ONE engagement (e.g., personal) via vault-config.md override. Do the `[!question] Outside yesterday's frame` callouts produce useful divergent items? Or do they manufacture spurious "novelty" the LLM had to invent? Watch for explicit-null prose ("today's gather largely continued yesterday's threads") — that's the signal Knob 2 will detect, not a failure mode.
- **Knob 2 (capture-frame-drift):** only fires if opted in via `tripwire_aspects` override AND ≥5 days of memory.md syntheses available. After 5+ days of memory accumulation, do drift flags fire too aggressively (false positives) or too conservatively (false negatives)? This is the threshold-tuning input.
- **Knob 3 (lens_shift):** only fires if opted in via `cadences.lens_shift` override. Each Saturday 07:00, a cold-MB companion atomic note should appear at `spice/cowork/daily/YYYY/MM-Month/YYYY-MM-DD/morning-briefing-cold-<engagement>.md`. Daily Hub's `## Lens-shift companions` section should render the warm + cold pair side-by-side via `CoworkLensShiftCards`. Do the framings differ materially, validating the empirical-anti-echo hypothesis?

If any regression, file v0.95.x PATCH candidate (threshold tuning, prose adjustment, knob-composition refinement, or CustomJS rendering fix).
