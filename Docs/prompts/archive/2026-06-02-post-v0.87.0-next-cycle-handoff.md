## Open carry-forwards from v0.87.0 (newly surfaced)

### FLN-v87-1 — corpus-density empirical validation owed at deploy

The `min_similarity: 0.45` threshold is a design-time guess based on the sequencing decision's "200 ticks noisy" analysis. The empirical lower bound is unknown until v0.87.0 deploys against the real accuris / headspace corpora. Post-deploy task: review the first 3-5 morning briefings on each consumer vault. If Echoes callouts surface obviously-unrelated matches (low-similarity matches passing threshold), raise the bound to 0.55 / 0.65. If relevant matches are consistently filtered out (callout omits even on days with clear historical analogues), lower the bound. A v0.87.1 PATCH could ship the empirically-validated threshold.

**Candidate:** v0.87.1 PATCH if empirically wrong; no-op if 0.45 turns out to be right.

### FLN-v87-2 — `/cowork recall <query>` USER-INVOCATION skill deferred

v0.87.0 auto-includes Echoes in morning-briefing's pre-flight 3b. Explicit user-driven semantic query against the memory corpus (vs the automatic include) is deferred. A `/cowork recall <query>` slash command would surface `cowork:gather-semantic-memory` directly with a user-supplied anchor + on-the-fly `top_k` / `min_similarity` args. Could ship as v0.87.1 alongside FLN-v87-1's threshold polish once the auto-include behavior is empirically validated. Per design § 1.4.

**Candidate:** v0.87.1 PATCH or MINOR (depending on what other USER-INVOCATION surfaces are bundled).

### FLN-v87-3 — Tier 2 prioritization timing observation

The sub-skill prefers Tier 2 (synthesis.md) over Tier 1 (memory.md) when present at threshold. But Tier 2 corpus only exists after `cowork:synthesize-week` has fired at least once per engagement — which happens on the first Friday after v0.85.0 deploy. For the first week post-v0.87.0 deploy (before the first Friday), retrieval falls through to Tier 1 (memory.md) only. **Not a regression** — just an empirical observation that the Tier 2 prioritization advantage manifests gradually over the first 2-3 weeks of accumulated weekly syntheses.

**Candidate:** observe-and-defer. Not a code change; just a documentation note for the deploy validation report.
