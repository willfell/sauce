## Open questions for the v0.99.1 doctor brainstorm

The doctor's SHAPE is locked (embedded, 4 checks — 2026-06-11 brainstorm Q4). These remain open and should be resolved before the design is locked:

1. **Where does the doctor write its detail log?** A `[doctor]`-tagged section in the existing `reconciler-log.md` (free — the reconciler already owns the write path; capped-30 contract already exists) vs a NEW `memory/<eng>/doctor-log.md` (separable history; another runtime-created file). Lean: reconciler-log entry — fewer files, and the morning-brief callout is the user surface anyway.

2. **Does the digest render daily or only on anomaly?** Daily digest = a standing satisfaction-trend pulse in every morning brief (reading-load cost — v0.98.0's reduction arc pushes against it). Anomaly-only = silent when green (the v0.96.1 heartbeat posture: silent on green). Lean: anomaly-only for checks 1-3; the self-grading digest (check 4) may deserve a weekly slot instead of daily.

3. **How does version-drift detection read wrapper stamps?** The cloud wrapper body isn't directly readable at reconcile time from the vault — candidates: read the sidecar's `generator`/`generated_by` stamp from yesterday's notes (what version COMPOSED the note — indirect but already on disk) vs a self-stamp clause in the wrapper that writes its own version into the sidecar at fire time (direct but needs a wrapper-template change + align run to deploy). Resolve against what's actually present in the live sidecars (verify-before-design).
