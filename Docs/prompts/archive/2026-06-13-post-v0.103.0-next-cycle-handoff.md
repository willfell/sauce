# Post-v0.103.0 next-cycle handoff

This doc is the session-start reference for the FIRST conversation after v0.103.0 closes + deploys. The section-hubs cycle replaced v0.102.0's single-page Confluence-style Docs Hub with a hierarchical navigation tree, capped at 2 nesting levels (project → section → sub-section → docs). Driven by ONE post-dogfood observation on accuris: "how am I to know what is in which section within Docs?"

**Three new helpers** materialized: **Breadcrumb** (clickable wikilink trail on every node — project / docs-hub / section-hub / doc-note); **ProjectDocsIndex** (replaces `ProjectDocsSections` on `Docs.md` — section cards + dashboard chips + `+ New Section` / `+ New Doc` shortcuts; defaults to `[[Knowledge]]` / `[[Notes]]` when sections absent); **SectionHub** (depth-aware section + sub-section render; depth-1 hubs show sub-section cards + `+ New Sub-Section`; depth-2 cap suppresses sub-section UI). **One new template** (`Template, Section Hub.md`) + **one rewritten** (`Template, Docs Hub.md` now invokes `Breadcrumb` + `ProjectDocsIndex`) + **one extended** (`Template, Doc Note.md` prepends the breadcrumb marker + block). **`ProjectNavButtons`** grows section-hub depth 1 + 2 context branches (sibling-sections / sibling-sub-sections rows).

**Migration** (NEW `applyProjectSectionsHubMigration`) heals existing v0.102.0 vaults end-to-end: rewires `Docs.md` body from `ProjectDocsCards` / `ProjectDocsSections` → `ProjectDocsIndex` + materializes Section Hubs per existing `docs/<slug>/` subfolder + recurses ONE level for Sub-Section Hubs + migrates doc-note `section: "Knowledge"` (string) → `section: "[[Knowledge]]"` (wikilink) + adds `sub_section` field when applicable + injects breadcrumb dataviewjs block at the top of every doc-note body (guarded by `<!-- breadcrumb-v1.17.0 -->` marker) + migrates project `sections[]` frontmatter from strings to wikilinks + default-section guarantee (Knowledge + Notes always present). Idempotent per-project; failure-loud per-project.

No cowork surface touched; contract 0.35.1 UNCHANGED; mechanism count 17 UNCHANGED. Workshop 0.102.0 → 0.103.0; project blueprint 1.16.0 → 1.17.0; all other versions UNCHANGED.

- **v0.104.0 cowork:doctor (default).** Displaced THREE cycles by v0.101.0 + v0.102.0 + v0.103.0; shape locked from 2026-06-11 brainstorm. The KPI is 5× richer with per-cadence satisfaction signal + 4+ days of accrual since v0.101.0 deploy.
