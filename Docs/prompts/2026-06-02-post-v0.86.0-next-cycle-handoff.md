## Open carry-forwards from v0.86.0 (newly surfaced)

### FLN-v86-1 — compose helper consolidation question

4 per-orchestrator helpers chosen over single consolidated switch-based composer at v0.86.0 design time. Empirically correct given each orchestrator's body context differs enough to justify separation (midday tick-log only; eod dual tick-log + day-synthesis; weekly week-synthesis + carry-forward bullets; monthly aggregated multi-week). Consolidation is a refactor candidate only when patterns prove uniform across future wire-through cycles (e.g., v0.87.0 semantic-retrieval + v0.88.0 distill-week additions). Defer the question until at least 2 more wire-through cycles have shipped + the helper count exceeds 6.

**Candidate:** design-only / observe-and-defer. Refactor cycle would be doc-only or PATCH-shaped.

### FLN-v86-2 — stash + dogfood install collision pattern

`git stash` + dogfood install collide because install writes to `CLAUDE.md` + `ranch/claude-surface-registry.json` + `ranch/platform-installed.json` that aren't idempotent with stash semantics (stash captures working-tree state, but install writes are post-commit-state-dependent). Future cycles needing selective drift management should use `git checkout HEAD -- <files>` for targeted restoration rather than `git stash` + unstash across install boundaries.

**Candidate:** doc-only PATCH; codify in `Docs/agent-guides/build-test-verify.md` § Dogfood install.

### FLN-v86-3 — weekly-review + monthly-review missing v0.85.0 §0.3 backlink
