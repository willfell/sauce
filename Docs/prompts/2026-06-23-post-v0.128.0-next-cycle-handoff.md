## Standing landmines a finance cycle hits

Read these before designing the G7 cycle — every one of them bit v0.128.0:

- **Version-short-circuit needs a blueprint bump.** A migration-bearing finance cycle MUST bump the finance blueprint version (and the seed subscription pin), or `applyFinanceMigrations` is version-short-circuited and the seed harness never exercises the migration — red asserts that look like migration bugs but are version no-ops.
- **#24 — triple-site catalogue.** A finance version bump touches THREE files: the blueprint manifest `version`, the workshop self-subscription pin, AND `platform/manifest.json` `blueprints[].finance.version`. Missing the catalogue row surfaces as install `event: "skip"` `"subscription pins finance@X but workshop has Y"` → exit 1 with **empty stderr**.
- **#26 + rebaseline fixture restore.** `npm run seed:rebaseline` ratchets multi-test fixtures (the Legacy Project section-hub anchors) into post-migration shape, breaking `HC-V01190-PROJ` + `HC-V01241-SECHUB`. After rebaseline, restore those fixtures from `seed-vault-prev` (sanctioned per landmine #26).
- **#16 — VERSION-range sweep.** Bump the `HC-V0*-VERSION-*` assertions in `run-helper-cases.js` + `run-bootstrap.js` and add an `HC-V0128-VERSION-*` family (PATCH-tolerant `/^0\.128\.\d+$/` form). v0.128.0 widened the sweep to 128 / finance → 10.
