# Post-v0.102.0 next-cycle handoff

1. **Sections.** Doc-notes get foldered under `docs/<section-slug>/`; two platform defaults ship (`Knowledge`, `Notes`); per-project override via `sections: []` in project frontmatter; `section:` doc-note frontmatter mirrors the folder (folder wins on conflict). Tags do orthogonal categorization.

Idempotent.
