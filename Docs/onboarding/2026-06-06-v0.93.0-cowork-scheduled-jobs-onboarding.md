# v0.93.0 cowork scheduled-jobs sync — end-to-end onboarding

This walks you through everything from "v0.93.0 just shipped" to "every Cowork scheduled task on claude.ai is up-to-date with the new contract." Covers BOTH engagements (headspace + accuris) and BOTH machines (this workshop dev box + the laptop where crons actually fire).

**Status as of doc generation (2026-06-06 18:39 MDT):** This machine is fully onboarded. The laptop still needs the brew-upgrade + sauce-update legs. Both engagements' wrapper files are ready to paste.

## What v0.93.0 ships (1-paragraph recap)

`/cowork sync-scheduled-jobs <engagement_id>` reads the engagement's actual `prefs.mcps` state + the canonical contract (`spice/cowork/data/scheduled-job-contract.json`) and emits a paste-ready wrapper file at `spice/cowork/scheduled-job-wrappers/<engagement_id>.md`. The file has frontmatter (sauce + cowork + contract versions; generated_at; warnings) + a collapsed "How to use" callout + 5 numbered sections (one per cadence: morning-briefing / midday-tripwire / eod-review / weekly-review / monthly-review) + each section is a 4-backtick-fenced paste-ready prompt body for the matching claude.ai scheduled task. Fully dynamic — dispatch lines (`<kind> served-by <UUID>; …`) computed kind-by-kind from your actual prefs.mcps. New MCP shapes work without any contract changes.

After every cowork MINOR bump that touches the cron contract, re-run `/cowork sync-scheduled-jobs <engagement_id>` to refresh, then paste each fenced block into claude.ai's Cowork task editor.
